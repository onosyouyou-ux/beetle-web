REPORT COMMENT MAKER

所見の下書き、
人数分まとめて。

子どものようすのメモを、1行に1人ずつ貼るだけ。通知表の所見（行動の記録・総合所見）の下書きが、クラス全員分そろいます。 文字数・文体・観点は先生が指定できます。

無料で使ってみる ›

登録不要・ブラウザだけで使えます／名前は入力しません

学期末、ここで止まっていませんか

1人目で止まる

何を書くかは頭にあるのに、最初の一文が出てこない。それが人数分ある。

同じ言い回しばかりになる

「意欲的に取り組みました」が並んでしまい、後半ほど書き分けが苦しくなる。

気になる点の書き方に迷う

事実は伝えたい。でも保護者が読んで責められたと感じない言い方が難しい。

字数が合わない

書いてから欄に入らず、削って意味が変わる。数えながら書くのが地味に重い。

所見メーカーでできること

A

メモから人数分いっぺんに

1行1人でメモを貼れば、クラス全員分の下書きが並びます。8人ずつ順に作るので、40人でも操作は1回です。

B

短所は「次に伸びる書き方」へ

気になる点はそのまま書いてください。事実を消さずに、次の学期に向けた前向きな言い方に置き換えます。決めつけや他の子との比較は書きません。

C

字数・文体・観点を指定

80〜200字、です・ます／である、学習面・生活面などの観点を選べます。欄の大きさに合わせて作れるので、あとで削る作業が減ります。

名前を、預かりません

このツールには子どもの名前を入れる欄がありません。並びは出席番号だけです。 送られるのは先生が書いたメモの文章で、サーバーにもブラウザにも保存していません。画面を閉じれば残りません。

入力（1行に1人）

3 運動会のリレーで最後まで走りきった。授業中に隣の子と話してしまうことがある。

➜
できあがり（120字・です・ます）

運動会のリレーでは、最後まで力を抜かずに走りきりました。行事に向かう気持ちの強さが、そのまま体の動きに表れていました。授業では、気づいたことを近くの友達に伝えたくなる場面があります。話す時間と聞く時間を意識できると、よさがさらに生きてきます。

※ 出力はあくまで下書きです。事実の確認と最後の言い回しは、必ず先生の手で直してください。

使い方は3ステップ

1ようすをメモする

1行に1人ずつ、その子で見えたことを短く。名前は要りません。行頭に出席番号を付けておくと、あとで名簿と突き合わせやすくなります。

2学年・文字数を決める

学年・学期・文字数・文体を選びます。入れたい観点があれば選びます。1人あたり2案を出すこともできます。

3作って、直して、使う

人数分の下書きが並びます。画面で直接直せるので、言い回しを整えてからコピーして通知表に貼ってください。

よくある質問

子どもの名前や成績は送られますか？+
名前を入力する欄がありません。送られるのは先生が書いたメモの文章だけで、サーバーにもブラウザにも保存していません。画面を閉じれば残りません。
気になる点を書いても大丈夫ですか？+
そのまま書いてください。事実は消さずに、次の学期に向けた前向きな言い方に変えて文章にします。決めつけや、他の子との比較は書きません。
そのまま通知表に貼っていいですか？+
下書きとして使ってください。所見はその子を見てきた先生の言葉です。事実の確認と最後の言い回しは、必ず先生の手で直してください。
何人分まで一度に作れますか？+
人数の上限はありません。8人ずつ順番に作るので、40人でも1回の操作で最後まで進みます。途中経過は画面に出ます。
文字数や文体は指定できますか？+
80字から200字まで選べ、です・ます調とである調を切り替えられます。通知表の欄の大きさに合わせて指定してください。
