# 学級通信メーカー SPEC

学校の先生が学級通信・学級だよりを簡単に作れるWebアプリ。
先生は記事の素材を入力するだけ。AIが文章を整え、紙面に流し込む。

---

## コンセプト

- 先生は「時間がない」層。入力は最小限、AIが膨らませる
- **写真ではなくイラストを使う**ことで、子どもの顔出し（個人情報・肖像権）問題を回避する。これが最大の差別化ポイント
- 「いい感じにしといて」では動かない。だから入力欄が意図を持つ設計にする

---

## 技術スタック

- Next.js（App Router）
- Claude API：記事生成・再生成（APIキーはVercelのEnvironment Variablesで保護。`/api/generate` のサーバー側で叩く）
- OpenAI API（gpt-image-1）：イラスト化（※後から接続。第一段階では未実装でよい）
- Vercel：デプロイ
- イラスト素材：プリセット画像を切り出して `public/illustrations/` に配置

## 画面構成

日本人向けUI：**左にプレビュー、右に入力エリア**。

### 上部
- タイトル（アプリ名）

### 左：プレビューエリア
- 上部にプルダウン3つ
  - テンプレート（クラスの性格 × イベント）
  - フォント（ゴシック丸 / ゴシック / 明朝）
  - フォントサイズ（小 / 中 / 大）
- 紙面プレビュー（新聞風レイアウト）
- プレビュー下に**修正指示欄**（自由記述テキストエリア）＋「この内容で再生成する」ボタン

### 右：入力エリア
- **記事ボックス**（可変・何個でも追加可能）
  - テキスト入力（箇条書きでOK）
  - イラスト選択プルダウン（プリセットから選ぶ）
  - 画像アップロード＋「イラスト化」ボタン（※第二段階）
  - 削除ボタン
- 「記事を追加」ボタン
- **固定欄**（3つ）
  - 今月の行事・イベント
  - 忘れ物・持ち物連絡
  - 注意事項（赤系で目立たせる）
- 余白提案（記事が少ないとき「固定欄を入れると余白がちょうどよくなります」）
- 「新聞を生成する」ボタン

## 中核ロジック

### 区切りは動的に決まる
- 区切りを最初に固定しない
- **先生が入力した記事の数だけ、見出し＋本文を作る**
- 空いたスペースは、固定欄（行事・忘れ物・注意事項）や季節ネタで埋める

### 字数で紙面を充填
- 紙面サイズは固定
- 入れる総字数を決めておく（目安400〜500字）
- 項目が少なければ文字を大きく・余白広めに、多ければ小さく詰める
- → 常に「埋まって見える」

### AIのルール（重要）
- **先生が書いた事実だけを使う。架空のエピソードや子どもの名前は絶対に作らない**
- 字数調整は、フォントサイズ・余白・段数で吸収するのを主にする
- 書き足しは接続的な最小限のみ。特定の子やイベントの中身は創作しない
- → 保護者に配るものなので、事実の捏造は厳禁

---

## テンプレート（クラスの性格 × イベント）

骨格・トーンをセットで持つ。ガチガチのレイアウトではなく「ゆるい雰囲気」だけ規定。

### クラスの性格（トーン）
| 種類 | トーン | フォント傾向 | 色 |
|---|---|---|---|
| 低学年・やわらか | 丸っこい・元気 | 丸ゴシック | 明るい・彩度高め |
| 高学年・すっきり | 大人っぽい・簡潔 | ゴシック/明朝 | 彩度落とす |
| 仲良し学級 | やさしい・幼げ | 丸ゴシック | やわらかい |

### イベント（見出し・飾りがゆるくマッチ）
運動会 / 遠足 / 通常号 / 卒業 など

掛け合わせで使う（例：低学年 × 運動会）。

## イラスト機能

### プリセット選択（第一段階）
- プリセットイラスト30種を `public/illustrations/` に用意
- 記事ボックスのプルダウンから先生が選ぶ
- カテゴリ：運動会・遠足・修学旅行・入学式・卒業式・文化祭・学芸会・体育祭・合唱・クラブ活動・委員会活動・四季の自然（春夏秋冬）・授業・テスト・勉強・給食・読書・図書室・清掃活動・けが/保健室・安全/登下校・あいさつ/マナー・ボランティア活動・地域交流・校外学習・キャンプ・将来の夢

### 元画像の切り出し
- 元画像：6列 × 5行 = 30個のイラストが均等配置された1枚のPNG
- Pythonで座標計算して1枚ずつ切り出す
- 各イラストの下にラベル文字があるので、イラスト部分のみトリミング（ラベルは切り落とす or 別途名称マッピング）
- ファイル名は内容に対応（例：undokai.png, ensoku.png）

### 写真→イラスト化（第二段階）
- OpenAI gpt-image-1 で実装
- **コスト注意**：画像生成は1枚あたり課金。運動会で大量生成すると効く
- **顔の扱い**：実在の顔を別人化しつつ場面は伝える。プロンプトで「特定の個人を再現しない、雰囲気を描く」と寄せる
- 画像ごとに都度イラスト化（一括ではない）

## ワークフロー

1. **素材入力**（先生）：記事を箇条書きで。固定欄も埋める
2. **イラスト選択**（先生）：記事ごとにプルダウンで選ぶ
3. **一括AI生成**：「新聞を生成する」を押す。全入力をまとめてAIが紙面化
4. **添削**（先生）：修正指示欄に「○○の記事を温かい表現に」等を書く
5. **再生成**：前回の出力＋修正指示で作り直す。レイアウト再調整も含む
6. 納得いくまで4〜5を繰り返す

## データ構造（AI出力）

JSON形式：

```json
{
  "articles": [
    { "heading": "見出し（10字以内）", "body": "本文（50〜100字）", "illustration": "undokai" }
  ],
  "events": "行事テキスト",
  "items": "忘れ物・持ち物テキスト",
  "caution": "注意事項テキスト",
  "fill": "余白補填用の季節ネタ1文"
}
```

## 実装フェーズ

### フェーズ1（まず動かす）
- 入力UI（記事可変＋固定欄3つ）
- テンプレ・フォント・サイズのプルダウン
- Claude APIで記事生成（`/api/generate`）
- 新聞風プレビュー描画
- 修正指示→再生成
- 余白提案

### フェーズ2（イラスト）
- プリセットイラスト切り出し＆配置
- 記事ボックスのイラスト選択プルダウン
- プレビューにイラスト反映

### フェーズ3（イラスト化）
- OpenAI gpt-image-1接続
- 写真アップロード→イラスト化

### フェーズ4（仕上げ）
- 印刷・PDF出力（A4縦）
- Vercelデプロイ

## 注意・論点メモ

- 字数合わせでAIに作文させない（事実の捏造防止）
- イラスト化のコスト管理（枚数課金）
- 新聞スタイル（情報詰め込み型）は入力負荷が高い→低学年・すっきり型から先に作る
- 印刷前提なのでA4縦サイズで設計
