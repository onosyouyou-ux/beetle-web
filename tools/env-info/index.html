ブラウザから分からないこともある

ブラウザは、自分がどの端末で動いているかを全部は教えてくれません。個人の特定に使われないよう、User-Agent（ブラウザが名乗る文字列）はわざと大ざっぱにされてきました。Windows 10 と 11 はどちらも「Windows NT 10.0」、macOS は何年たっても「10.15.7」、Android は機種名が消えて「Android 10; K」です。

Chrome と Edge には、それとは別に正確な OS のバージョンや機種名を問い合わせる仕組みがあり、このツールは使えるときはそちらを優先します。使えないときは、推測で埋めずに「見分けられません」「ブラウザが隠しています」と書きます。分からないものを分かったことにしないほうが、報告を受け取る側は判断を誤りません。

iPhone と iPad のブラウザは、Chrome でも Firefox でも中身は Safari と同じ WebKit で動いています。「iPhone の Chrome だけで出る」と報告があったら、Safari でも出るかを先に確かめると早く絞れます。再現手順の書き方は バグ報告の書き方、スクリーンショットから起票内容を作るなら これってバグなの？ をどうぞ。

よくある質問

Windows 11 なのに「Windows 10 または 11」と出るのはなぜですか？+
User-Agent という文字列には、Windows 10 と 11 のどちらでも「Windows NT 10.0」と書かれていて、見分けがつかないためです。Chrome と Edge はそれとは別に OS のバージョンを教えてくれるので、Windows 11 と判定できます。Firefox では見分けられません。
iPad なのに Mac と出るのはなぜですか？+
iPadOS の Safari は、パソコン向けのページを表示するために既定で Mac を名乗ります。このツールでは、Mac を名乗っているのにタッチ操作ができる場合に「iPadOS（Macと名乗っています）」と表示しています。
macOS のバージョンが 10.15.7 と出るのはなぜですか？+
Safari・Firefox・Chrome は、User-Agent に書く macOS のバージョンを 10.15.7 に固定しています。実際のバージョンではないので、このツールでは「ブラウザが隠しています」と表示します。Chrome と Edge では、別の方法で実際のバージョンを取得できます。
拡大率（devicePixelRatio）とは何ですか？+
画面の1ピクセルに、実際の液晶の点がいくつ使われているかを表す値です。高解像度のスマホやノートPCでは 2 や 3 になります。Windows の表示スケール（125%など）や、ブラウザのズームでも変わるので、「表示が崩れる」系の不具合ではこの値があると原因を絞りやすくなります。
問い合わせてきたお客さまに使ってもらえますか？+
使えます。このページのURLを送り、「開いてコピーボタンを押し、返信に貼ってください」とお願いすれば、ブラウザやOSを口頭で聞き出す必要がなくなります。貼る前に、送りたくない項目のチェックを外すこともできます。
取得した情報はどこかに送られますか？+
送られません。情報の取得も整形もブラウザ内（あなたの端末上）で行っていて、サーバーには何も送信していません。コピーした内容をどこに貼るかは、あなたが決めます。
