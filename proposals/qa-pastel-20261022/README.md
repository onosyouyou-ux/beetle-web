# 検証ツール14枚：背景を淡い5色に変更
制作日：2026-10-22／Issue #197／ローカルブランチ codex/qa-pastel-197

組み込みimage_genによる既存画像の背景色編集です。全14回の編集プロンプトはprompts.jsonに記録。
和紙のベージュを水色・ミント・薄桃・ラベンダー・クリームへ置き換え、既存のツール名・濃紺・朱色・モチーフを保ちました。
色はcolors.jsonにカード単位で固定。添付された3列一覧の順序で、横・縦の隣同士に同色が来ないよう配置しています。

## 内容
- assets/images/qa-thumbs-pastel-20261022/：編集原寸PNG14枚、1200×675 JPG14枚、720×405 WebP14枚。
- proposals/qa-pastel-20261022/overview.png：カード本文を含む全体イメージ。
- proposals/qa-pastel-20261022/thumbnails.png：サムネだけの一覧。
- proposals/qa-pastel-20261022/index.html：変更前と変更後を切り替えて比較。
- colors.json：色の固定対応表。hexは編集時の目安で、紙の風合いによる色の揺らぎを含みます。
- prompts.json：各画像の編集プロンプト。
- verification.json：枚数・画像寸法・掲載用合計容量の確認結果。
- render-preview.py：元のtest-tools.htmlと元画像を読み込む、プロジェクト内での再生成用スクリプト。

HTMLプレビューはZIPをすべて展開してから開いてください。before/は比較用の元画像縮小版です。
今回の対象はスクリーンショットの操作用14本です。参照用6本の現行別構成は対象外。
素材とレビュー用プレビューを作成しました。サイトの画像参照の差し替え・本番反映は未実施です。
