10MBのPDFを、どこから持ってきますか。テスト用のダミーファイルを作る無料ツール

アップロードの上限が10MBだと仕様書に書いてある。では、それを確かめるための10MBのPDFは、どこから持ってきますか。

この質問、テストの現場では毎回出ます。そして毎回、誰かのデスクトップにある実ファイルが使われます。去年の請求書。社内報のPDF。前の案件のスクリーンショット。動くことは動くのですが、これは静かに危ない橋です。

実ファイルの使い回しは、二重に事故ります

ひとつは中身の問題です。テスト環境とはいえ、実在の個人名や取引先名が入ったファイルをアップロードすると、それはもうテストデータではありません。スクリーンショットを不具合票に貼った瞬間に、チケットへ流出します。

もうひとつは、サイズが目的の値ぴったりにならないことです。上限が10MBなら、確かめたいのはちょうど10MBと10MBを少し超えたものです。手元にあるのは 8.3MB と 12.7MB。境界に立てないまま「まあ通ったからOK」で終わります。境界値でしか出ないバグは、だいたいこうして残ります。

探す時間も馬鹿になりません。「大きいファイル 何か持ってない？」とチャットで聞いて、返事を待って、共有ドライブから落として。1回5分としても、テストのたびに発生します。

サイズと形式を選んで、その場で作る

作ったのはダミーファイル生成ツールです。形式とサイズを選ぶと、その場でファイルができてダウンロードされます。

  • 画像 … PNG・JPEG・SVG・GIF
  • 書類 … PDF・Excel（xlsx）・Word（docx）・CSV・テキスト
  • メディアほか … 動画・音声・ZIP など。あわせて19形式
  • サイズ … 1KB・10KB・100KB・500KB・1MB・5MB・10MB から選択

Excel と Word は、拡張子だけ変えた偽物ではなく、実際に開ける形で作っています。「拡張子は通ったのに開けない」を検証と切り分けたい場面があるからです。

無料・登録不要。ファイルはどこにも送りません

業務で使う道具なので、そこが気になると思います。

  • 無料 … 課金も回数制限もありません
  • 登録不要 … アカウントもメールアドレスも要りません
  • ブラウザの中だけで動きます … 生成も判定も、その端末の上で完結します。サーバーには何も送っていません
  • インストール不要 … 会社のPCに何かを入れる稟議は要りません

どこで効くか

いちばん出番があるのはアップロード周りです。

  • 上限の境界 … 上限ぴったりと、そのすぐ上。エラーメッセージが正しく出るか
  • 許可されていない形式 … 画像だけ受け付ける欄に、PDFやZIPを渡したときの挙動
  • 大きいファイルの途中経過 … 進捗表示、タイムアウト、二重送信の防止
  • 一覧・詳細での見え方 … 長いファイル名、日本語のファイル名、サムネイルが作れない形式

「大きいファイルを入れたらどうなるか」は、仕様書に書かれないまま実装されることが多い場所です。書いていないから確認されず、確認されないから本番で出ます。道具が手元にあると、確認のハードルがぐっと下がります。

正直に書くと、中身は意味のないデータです

このツールが作るのは、指定したサイズと形式を満たすだけのファイルです。中の文章や画像に意味はありません。文字コードの検証や、業務データの再現には向きません。

文字化けや機種依存文字を試したいときは意地悪テストデータ生成器、日付の境界を突きたいときは意地悪な日付ジェネレーターのほうが目的に合います。道具は分けたほうが、どちらも短く済みます。

探す時間を、確かめる時間に回したい

テストで時間を食うのは、たいてい確認そのものではなく準備のほうです。ファイルを探す、アカウントを作る、データを整える。ここを削ると、同じ工数でも見られる範囲が増えます。

上限の値をテストするのに、誰かの請求書を使わなくて済むようになるだけでも、作ってよかったと思っています。
