# ルビメーカー（旧: ふりがなメーカー） — ランディング用ブリーフ

文章を貼りつけるだけで、AIが漢字にふりがな（ルビ）を自動でふるWebツール。
画像から文章を読み込むこともできる。登録不要・無料。子どもの音読練習・教材づくり・やさしい日本語対応向け。

---

## コンセプト

- 使い方は「貼る→ボタン→できた」の3ステップのみ
- 「すべての漢字」と「むずかしい漢字だけ」の2モードで、対象読者（子ども／大人）に合わせられる
- プリントや本を写真に撮るだけでOK（OCR経由でテキスト化してからふりがな付け）
- 結果は「HTML（`<ruby>`タグ）」と「漢字(よみ)形式」の2種類でコピーできる

---

## 技術スタック

- Next.js 14（App Router）
- Claude API（`claude-sonnet-5`）：サーバー側（`/api/annotate`, `/api/ocr`）で呼ぶ。bug-checker型と同じくAPIキーを隠す設計
  - ふりがな付与：`output_config.format: json_schema` でJSON出力を強制（コードフェンス剥がし・パース失敗のケアが不要）
  - 画像OCR：`messages.create` に画像ブロックを渡して文章を書き起こし
- Vercel：アプリ本体は独立プロジェクト `rubi-shokunin`（`rubi-shokunin.vercel.app`）としてデプロイ
- SEO：本体ドメイン（beetle-web.jp）に静的ランディング `tools/rubi-shokunin/index.html` を配置。アプリ側の`canonical`/`og:url`はこのランディングURLを指す

## 中核ロジック

### ふりがな付与（`/api/annotate` → `src/lib/claude.ts` の `annotate()`）
- 文章を `segments`（`{ text, ruby }` の配列）に分割させる。`text` を順番に連結すると元の文章と完全一致することをシステムプロンプトで強制
- ひらがな・カタカナ・英数字・記号のみの断片は `ruby` を空文字にする
- モードで振り分けルールを変える：
  - `all`（すべての漢字）：漢字を含む語に基本的にすべてふりがな
  - `hard`（むずかしい漢字だけ）：小学校低学年で習う漢字は除外し、読みにくい漢字・人名・専門用語・当て字のみ
- サーバー側で文字数上限（800字）をチェックしてから呼び出す

### 画像からの読み込み（`/api/ocr` → `extractText()`）
- 対応形式：JPEG / PNG / GIF / WEBP
- base64送信サイズの上限あり（Vercelのリクエストボディ上限4.5MBに収まるよう約4.2MB相当で制限）
- 画像に文章が見当たらない場合はモデルに `NO_TEXT_FOUND` を返させ、422エラーとしてユーザーに伝える
- 書き起こしたテキストをそのまま入力欄に反映（ふりがな付けは別ボタンで実行）

## 注意・論点メモ

- 一度に処理できる文章量は400〜500字目安（サーバー側上限は800字）。長文は分割前提のUI
- 画像OCRは「文章の書き起こし」までで、ふりがな付けとは別リクエスト（2段階）
- 顔写真等のプライバシー配慮は対象外（学級通信メーカーと異なり、扱うのは印刷物のテキストのみ）
