# 班分けメーカー（`tools/hanwake/`）

- **目的**: 名簿と配慮からグループ分けを作る先生向けの静的ツール。**席替えメーカーの姉妹ツール**。
  席替えのFAQに「班の形の席にはできますか？」という質問を置いていた（＝需要を想定していた）ので、そこを埋める
- **由来**: 席替えと同じ「制約を守る配置をランダムに探す」問題なので、解法・名簿UI・印刷をほぼ流用できる。
  新規ツールの中でいちばん安く出せる、という理由で 2026-08-24 に着手した
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  配色・トーンは `sekigae.css` に揃える（先生が職員室で使う画面）
- **主要素**: `#hw-rows`（名簿の行）・`#hw-rules`（配慮の行）・`#hw-num`（班の数）・`#hw-per`（1班の人数）。**名簿の人数とは切りはなして自由に選ぶ**（班の数 × 1班の人数 ＝ 班に入る人数。画面の単位は「人」「メンバー」で、「席」とは言わない）。初期値は班の数・1班の人数・男女比とも「---」（未選択）。班の数を選ぶと班の枠だけ出す（1班の人数が未選択なら中は空）。名簿の人数と合わないときは「おすすめ配置にする」（いまの班の数のまま均等に配る）を出す。「見本を入れる」は名簿（名前・性別・配慮）だけ入れ、1は触らず班分けもしない（押すのは先生）。空の班の枠で「＋ メンバー」「✕」「＋ 班を足す」により班ごとに人数を変えられる（プルダウンを選び直すと戻る）。名簿が席より少なければ、なるべく同じ人数になるよう配る。多ければ「班のメンバーの枠が足りません」・
  `#hw-count`・`#hw-plan`・`#hw-sample`・`#hw-gen`／`#hw-again`・`#hw-board`（班カード）・`#hw-msg`・
  `#hw-info`・`#hw-out`（TSV。画面には出さず「表をコピー」で渡す）・`#hw-copy`・`#hw-download`・`#hw-print`

## 2026-10-04 作り直し（席替えメーカーと同じ型）

- **操作の順番を見せる**：手順バー `#hw-stepbar`（1 班の数を決める → 2 名簿と配慮を入れる → 3 班分けする → 4 手直しして印刷）。
  名前が空で班の数も触っていない＝1、班の数を選んだ＝2、名前あり＝3、結果あり＝4。枠の見出しに同じ番号。
  **オレンジで塗るのは「班分けする」（下）と「再配置する」（結果の枠）だけ**。名簿の上の `#hw-gen2`・CSVのボタンは白い枠
- **1の枠**（`#tool`）：分け方・班の数を選ぶと、すぐ下に空の班の枠（1班 5人…）が出る。班分けすると同じ枠（`#hw-board`）に結果が出る（席替えのようなタブは不要）
- **名簿は1人1行**（`#hw-list`）：番｜なまえ｜そろえる項目のボタン｜配慮（配慮の列の「＋ 追加」から 別々・同じ・ちらす・リーダー。1人に何個でも）｜結果の班｜✕。
  最初は10行、`＋1人／＋5人／＋10人`。複数行を貼るとその行から下へ流し込む。Enter で次の行。空欄は「3番」
  - 別々・同じ：相手をプルダウンで選ぶ（2人1組）。ちらす：記号 A〜E を選び、同じ記号の子を1班に1人ずつ
  - **固定**（2026-10-05）：「固定」で班を指定するとその班に必ず入れる（`固定3` のようにCSVに書く）。手直しの入れ替え候補からも外す。ない班・入りきらないときはエラー
- **リーダー**（2026-10-04 ユーザー要望）：リーダーにした子を各班に1人ずつ配り、班のいちばん上に「リーダー」と出す（印刷にも出す）。
    班の数以下なら「1班に1人まで」を必ず守る（別々の組として解く）。多いときは「そろえる」で各班に均等に配り、その中から1人をリーダーにする。
    少ないときは、その班はいちばん上の子をリーダーにして「リーダーにした子がいない班が○班」とお知らせ。
    **班のいちばん上の子がリーダー**（2026-10-05）。手直しで上に来た子がその班のリーダーになる。空の班の枠も、いちばん上を「リーダー」の席として見せる
- **手直し**：結果の子をドラッグしてほかの子に重ねると入れかえ、班の空いた所に落とすと移動（班の人数が変わる）。タップ2回でも入れかえ。
  配慮から外れたら `#hw-msg` に知らせる（止めない）。いちばん上の子がリーダー
- 名簿の名前欄に入ると結果のその子が光る。結果があれば名簿の各行に「3班・リーダー」
- **印刷**：班のカードを3列で A4 横1枚に。黒線・黒文字。**配慮の札はリーダー以外出さない**（掲示で配慮が周りに分かるため）
- **CSV**：共通の形。班の配慮のセルは `別々1`・`同じ1`・`ちらす1`（1〜5＝A〜E）・`リーダー` を `;` で並べる。
  以前のCSVの3人以上の「別々」は、空いている記号の「ちらす」として読む
- **消す前の確認**：名前か配慮が入っている行の ✕、名簿が入っているときの「見本を入れる」
- 2026-08-24 版にあった「まとめて貼り付け」（textarea）は、行への貼り付けで足りるので外した。FAQ「男女が同じくらい…」の答えが `\{NEW\}` のまま本番に出ていたのも直した

## 共通CSV（2026-10-04）

- 席替え・班分け（・これから作るクラス分け）で**1つのCSVを使い回す**。列は
  `出席番号 / なまえ / 性別 / 席の配慮 / 席 / 座席の形 / 班の配慮 / 班 / クラスの配慮 / 前のクラス / 新しいクラス`（`BeetleRoster.SHARED_COLS`）
- 各メーカーは**自分の列だけを読み書き**し、ほかのメーカーの列は読みこんだ値を人ごとに取っておいて（`keepExtras`）、保存のときそのまま書き戻す（`sharedRows`）
- 「○○の配慮」はメーカーごとに別の列。以前のCSVの見出し「配慮」は、自分の配慮列がないときだけ自分のものとして読む（`ruleColumnRole`）
- 画面・使い方・FAQ・ランディングでは「CSVは席替えメーカー・班分けメーカーで共通です。1つの名簿ファイルを使い回せます（ほかのメーカーの列はそのまま残ります）。」で言い回しをそろえる

## 保存はCSVファイルだけ（2026-08-24決定）

初版は localStorage に名簿を保存していたが、**配慮と前回の班までCSVに入るようにした時点で役割が重なった**ので外した。
理由：ブラウザ保存は端末ごとに分かれて職員室と自宅で共有できない／ファイルのほうが先生の手元に残って確実／
そして何より **「名簿は一切保存しません」と言い切れる**（このツール群の一番の売り）。席替えメーカーも同じにした。

- **CSVが唯一の保存形式**。列は `出席番号 / なまえ / <そろえる項目名> / 配慮 / 班`。
  1枚読み込めば名簿・そろえる項目・配慮・前回の班がすべて戻る
- **配慮は人ごとのセル**に `別々1`・`同じ1`・`ちらす2` の形で書く。**同じ種類＋同じ番号の人どうしが1つの組**。
  1人が複数の配慮に入るときは `別々1;ちらす2` のように `;` で並べる
- **「班」列があれば前回の班として読む**。結果を「この班ごとCSVで保存」したファイルを次回そのまま読ませる流れ
- **見出しから列の役割を自動判別**する（なまえ／性別・ラベル／配慮／班）。
  自分が書き出したCSVはクリック0回で読み戻せる。違えば列ごとのプルダウンで直せる
- CSV取り込みは Shift_JIS 自動判別・引用符つきセル対応。なまえは複数列えらべる（姓と名が別列でも1人にまとまる）
- 書き出しは **UTF-8 BOM 付き**（付けないと日本語Excelで文字化けする）
- `js/class-roster.js` は席替えと共有。**localStorage を扱う機能は持たない**（CSVの読み取りと名前の読み取りだけ）

## 入力はフォーム（2026-08-24に textarea から変更）

初版はテキスト記法（`別々: 田中, 佐藤`）だったが、**名前を名簿と同じ書き方で打ち直させるのが負担**なので、
1人1行・配慮1件1行のフォームに変えた。**配慮の名前は名簿から選ぶ**ので、打ち間違いも
「名簿にありません」エラーも構造的に起きなくなった（そのぶんの検証コードも消えた）。

- **名簿の行**（`#hw-rows`）: なまえの入力＋そろえる項目のトグル＋×。`＋ 人を追加`、
  **なまえ欄で Enter → 次の人（最後なら1人増やす）**、**複数行を貼ると自動でその行数に展開**する。
  35人をExcelから貼る流れを殺さないため、`まとめて貼り付け`（textarea）も残してある
- **そろえる項目**: 1の `#hw-gmode`「男女比」で 均等（各班の人数をそろえる）／分ける（同じ班に混ぜない。混ざった班が出たらお知らせ）／気にしない を選ぶ。項目の名前と値は2の「男女のかわりに…」のたたみの中。項目名（`#hw-labelset-name`、既定「性別」）と選択肢（`#hw-labelset-input`、既定 `女, 男`）を分けて持つ。
  見出しには**項目名**を出す（「女／男」と値を並べると何の項目か分からない）。選択肢は**3つまで**（1行に収まらなくなるため）。
  項目を書き換えれば係や委員会にも使える。**「見本を入れる」では既定に戻すこと**（見本は女／男でラベルを付けてあるため）
- **配慮の行**（`#hw-rules`）: 種類のselect＋人のチップ＋×。人はプルダウンから選び、選択済みは候補から消える
- 内部モデルは `people = [{id,name,label}]` と `rules = [{id,kind,ids}]`。
  **rules は人を id で持つ**（名前で持つと、改名や同姓同名で壊れる）
- 表示名は `displayNames()` が確定させる（同姓同名は2人目以降に `（2）`）

## 配慮の種類

種類は3つ。`別々` と `ちらす` は**まったく同じ制約**（選んだ人全員がちがう班）で、
先生の意図が違うだけ。結果に出すタグは `tagOf` に選んだほうの語を覚えて表示する。

| 種類 | 内部 | 強さ |
|---|---|---|
| `別々` | apart | **必ず守る** |
| `ちらす` | apart（同上） | **必ず守る** |
| `同じ` | together | **必ず守る** |
| そろえる項目（名簿側のトグル） | balance | できるだけ守る |

## 班の決め方

- **人数の割り振り**: 35人4班なら 9,9,9,8（`groupSizes()`）。端数は先頭の班から1人ずつ足す
- **アルゴリズム**: `同じ` をつないで「かたまり」にし（union-find）、かたまり単位でランダムに配ってから、
  **同じ大きさのかたまりを交換する山登り**で詰める。ランダムに置くだけでは「前回と同じ顔ぶれ」が0にならなかったため。
  交換を同じ大きさに限るのは、班の人数を崩さないため
- **スコア**（小さいほどよい）: `前回と同じ組 × 10 ＋ そろえるの偏り × 3`。
  必須条件（別々・同じ・人数）を満たす配置の中から、いちばんスコアの低いものを選ぶ
- **「同じ」で組ませた2人は、前回と同じでも重複に数えない**。数えると「避けきれませんでした」という嘘の警告が出る
- **「そろえる」の偏りは、割り切れないぶんが必ず残る**（15人を6班なら理想2.5人で、実際は2か3にしかできない）。
  `minBias()` でその下限を先に出し、**下限を超えたときだけ**警告する。ここを固定値と比べると毎回誤報になる
- **作れないときは理由を具体的に出す**（`diagnose()`）: 班の数が人数より多い／`同じ` が1班に入りきらない／
  `同じ` と `別々` の矛盾／`ちらす` が班の数を超える／名簿にない名前

## 前回と同じ班を避ける

- 結果を「この班ごとCSVで保存」し、次回そのCSVを読ませる。「班」列から前回の顔ぶれを作る
- 読み込むと `#hw-prev` が出て「前回と同じ人と同じ班にしない」を選べる
- **エラーにはしない**（人数と班の数によっては原理的に避けきれない）。残った組数を `#hw-msg` に出す

## 検証済み（2026-08-24 ブラウザで実測）

- 見本（30人・6班・配慮4種）で**100回連続**して、別々・同じ・ちらす・人数・重複なし の**違反0件**
- 「保存 → 読み戻す → 引き直す」で前回と同じ組み合わせ **0件**（山登り導入前は毎回3組残っていた）
- 1回の班分けにかかる時間は約200ms
- エラー系はそれぞれ固有のメッセージになる（矛盾／ちらしきれない／同じが大きすぎ）
- フォーム化後も見本30人・6班で**60回連続**して違反0件。行の追加・削除・Enter送り・複数行貼り付け・
  トグル・CSVのラベル列取り込み・ひな形CSV・結果CSV（BOM付き）を実機で確認
- **CSVの往復**: 書き出したCSVを読み戻すと、列の役割が**クリック0回で自動判別**され、
  名簿・そろえる項目・配慮3件・前回の班がすべて復元される。そのまま引き直して前回と同じ組0件
- **人数より班が多いとき**は `#hw-plan` に「4人を6班には分けられません」と出す
  （初版は「6班（1班 0〜1人）」という意味のない表示になっていた）

- **手動確認観点**:
  - 「名簿はどこにも保存しません」の表示が消えていないか（このツールの前提そのもの）
  - 印刷プレビューで班カードが途中で切れないか（`break-inside: avoid` を入れてある）
