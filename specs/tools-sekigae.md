# 席替えメーカー（`tools/sekigae/`）

- **目的**: 名簿と配慮から座席表を作る先生向けの静的ツール。学級通信メーカーに続く**先生向け2本目**。
  名簿という個人情報を扱うため、**サーバーに一切送らないこと自体が機能**であり、それを画面上でも明示する（`.sk-privacy`）。
  2026-08-24に名簿の保存・CSV取り込み・前回の席の回避を追加したため、**「保存しない」ではなく「サーバーに送らない／保存はこの端末のブラウザの中だけ」**が正しい表現。
  `.sk-privacy`・使い方・FAQ・ランディングのPRIVACY節とFAQ（JSON-LD含む）は、この言い回しで揃えること
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ 余白はモザイクタイル `bg-mosaic.png`。
  ヘッダーは共通パーシャル、フッターはアプリ共通フッター（**ヒーローズバナーは付けない**＝テスト検証用ツールのみ）。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける。既存の使い方・配慮・FAQは利用中の補助情報として残す
- ヒーローに教室の画像と「リファレンス」リンクを表示し、`landing.html` へ移動する
- **トーン**: 子ども向けアプリ（さんすう・えいご）より落ち着いた配色。先生が職員室で使う画面という想定
- **主要素**: `#sk-list`（名簿と配慮の表。1人1行）・`#sk-add1`／`#sk-add5`／`#sk-add10`（行を足す）・`#sk-cols`／`#sk-rows`（2〜10。既定6×5）・`#sk-count`・`#sk-seats`・`#sk-sample`（見本）・`#sk-gen`／`#sk-again`・`#sk-board`（座席表）・`#sk-msg`・`#sk-info`・`#sk-out`（TSV）・`#sk-copy`・`#sk-print`

## 入力の読み方（2026-10-04 に表形式へ変更）

- **名簿と配慮は1つの表**（`#sk-list`）。1行＝1人で、最初は10行。`＋1人`／`＋5人`／`＋10人` で増やし、行末の ✕ で消す
  （消した人を相手にしていた「離す」「隣」も一緒に消える）。名前欄で Enter を押すと次の行へ（最後の行なら1行足す）
- **名前**: 1 欄に1人。`1 田中` のような出席番号つきでも名前だけを取り出す（`cleanName()`）。
  **複数行を貼ると、その行から下へ1人ずつ流し込む**（足りない行は自動で足す）。空欄の行は「3番」のように行番号で作る。
  同姓同名は2人目以降に `（2）` を付けて別人として扱う
- **配慮**: 行ごとの配慮の列の「＋ 追加」でプルダウンを足し、`前列`／`後列`／`固定`／`離す`／`隣` から選ぶ。**1人に何個でも付けられる**。
  `離す`・`隣` を選ぶと相手のプルダウン（自分以外の全員）、`固定` を選ぶと「○れつ」「○ばん」のプルダウンが出る。
  相手は行の id で持つので、あとで名前を直しても指定は外れない
- 同じ組み合わせを両方の行に書いても1つと数える。前列＋後列、離す＋隣（同じ2人）、固定2つ、相手の選び忘れはエラー

## 男女（2026-10-05 追加）

- 名簿の各行に性別のボタン（`—`／`女`／`男`。`.sk-seg`）。見出しは NO｜名前｜性別｜配慮｜席｜削除
- 「男女の並べ方」（`#sk-gender`）：気にしない／となりは男女（左右だけ交互）／前後左右とも男女（市松）。通路をはさんだ席は数えない
- 計算は席ごとに「女の席・男の席」の模様を毎回ランダムに作り、その色の席にだけ座らせる（通路で区切ったまとまり・行ごとに向きを変える）。
  模様の席より多い性別の子は、多いぶんだけ模様の外にして最後に置く（人数差があっても作れるように）。同性の隣が出たら数をお知らせし、40回引いていちばん少ない並びを使う
- ほかの配慮と両立できないときは男女の条件を外して作り、そのことをお知らせ（「前回の席」と同じ、守れる限り守る扱い）
- 「—」の子は条件の外。性別が1人も入っていないのに並べ方を選んだらお知らせ
- 結果の席は 女＝左に赤み・男＝左に青み の帯（並べ方を選んだときだけ。印刷には出さない）
- CSVの「性別」列を読み書きする（女／男・女子／男子・F／M などを 女／男 にそろえる）

## 座席の形（2026-10-04 追加）

- 入力パネルの一番上が「座席を作成」。空の座席表（`#sk-layout-board`）は最初から出ていて、横（列）・縦（行）を選ぶとその場で形が変わる（「座席を表示する」ボタンは確定ボタンと紛らわしいので廃止）
- 席のまわりに**点線の席**が出て、押すとそこに席を足せる（外側なら1列／1行広がる。上限は縦横10）。席の ✕ で消すと点線になり、押せば戻る。
  端の行・列が丸ごと空になったら詰める
- 席の形は `seatMap[r][c]`（true＝席あり）で持ち、計算では席のない所を `''` で埋めて置かない。前列・後列の定員、固定席が消した席にないかも `seatMap` で数える
- プルダウンで列・行を選び直すと、足した席・消した席はリセットして長方形に戻る
- できた座席表では、消した席は見えない空白として並びを保つ

## 席替えボタンと手直し（2026-10-04 追加）

- 「配置する」は名簿の枠の下の中央（`#sk-gen`）と、CSVボタンの行の右端（`#sk-gen2`）の2か所。1回作ったあとは両方とも「再配置する」になり、席の形を変えて結果が消えたら「配置する」に戻る。結果の枠の下の `#sk-again` も「再配置する」
- できた座席表の席は**ドラッグ＆ドロップ**か、**2つを順にタップ**（Enter／Space でも可）すると入れかわる。空席とも入れかえられ、消した席は動かせない
- 入れかえは止めない。配慮（固定・前列・後列・離す・隣）から外れたら `#sk-msg` に何が外れたかを出す
- **座席欄はタブ2枚**（`#sk-tab-shape`「座席の形」／`#sk-tab-result`「配置の結果」）。結果タブは席替えするまで押せない。
  形の下の `#sk-confirm`「この形で確定する」で点線と ✕ を隠して名簿へスクロール、もう一度押す（「座席の形を直す」）と編集に戻る。
  席替えすると形は確定扱いになり結果タブへ切り替わる。**形を変えたら前の結果は捨てる**（結果タブも押せなくなる）
- 「見本を入れる」は**名簿（名前・性別・配慮）だけ**を入れる。座席の形は触らず、配置もしない（2026-10-05。押すのは先生）

## 通路（2026-10-04）

- 「1 座席の形を決める」の `#sk-aisle`「通路を入れる」を押すと、列と列のあいだが押せるようになる（薄い点線で見せ、マウスを乗せるとその列のあいだ全体が光って「ここに通路を入れる」）。押すと通路、もう一度で消える。押し終わったら同じボタン（「通路を入れ終わる」）で抜ける
- 通路は `aisles[c]`（c れつ と c+1 れつ のあいだ）。**通路をはさんだ席は「隣」「離す」の周り1マス「前回と同じ隣」に数えない**。れつの番号は変わらない
- 結果の座席表・印刷にもすき間として出る。CSVの「座席の形」には `ooo|ooo/ooo|ooo` のように「|」で入れる
- 列を左に足す・端の列を詰めると通路の位置もずらす。横・縦のプルダウンを選び直すと通路も消える

## 共通CSV（2026-10-04）

- 席替え・班分け（・これから作るクラス分け）で**1つのCSVを使い回す**。列は
  `出席番号 / なまえ / 性別 / 席の配慮 / 席 / 座席の形 / 班の配慮 / 班 / クラスの配慮 / 前のクラス / 新しいクラス`（`BeetleRoster.SHARED_COLS`）
- 各メーカーは**自分の列だけを読み書き**し、ほかのメーカーの列は読みこんだ値を人ごとに取っておいて（`keepExtras`）、保存のときそのまま書き戻す（`sharedRows`）
- 「○○の配慮」はメーカーごとに別の列。以前のCSVの見出し「配慮」は、自分の配慮列がないときだけ自分のものとして読む（`ruleColumnRole`）
- 画面・使い方・FAQ・ランディングでは「CSVは席替えメーカー・班分けメーカーで共通です。1つの名簿ファイルを使い回せます（ほかのメーカーの列はそのまま残ります）。」で言い回しをそろえる

## 名簿の流し込み（2026-08-24追加）

名前を毎回打ち直さずに済ませるための入口が3つある。いずれも**ネットワークには一切出さない**。

- **保存はCSVファイルだけ**（2026-08-24決定。班分けメーカーと同じ）。localStorage への保存はやめた。
  理由：配慮も前回の席もCSVに入るようになって役割が重なった／ブラウザ保存は端末ごとに分かれて共有できない／
  **「名簿は一切保存しません」と言い切れる**。名簿まわりの共通部品は `js/class-roster.js`（CSVと名前の読み取りだけ。localStorageは扱わない）
- **CSVの列**は `出席番号 / なまえ / 配慮 / 席 / 座席の形`（2026-10-04 に「座席の形」を追加。1行目のセルだけに `ooooooo/oooooox` の形で入れる。o＝席あり・x＝席なし・「/」で行区切り。数字だと Excel が日付に変えるため文字にした）。座席の形の列がない以前のCSVは、前回の席から縦横だけ合わせる。配慮は人ごとのセルに `離す1`・`隣1`・`前列`・`後列`・`固定2-3`（列-番）を書き、
  `;` で複数並べられる。**同じ「離すN」「隣N」どうしが1つの組**（書き出しは2人1組で番号を振る。読みこみで3人以上の組は全ペアとして扱う）。「席」列は `2れつ3ばん` の形で、あれば前回の席として読む
- **見出しから列の役割を自動判別**する（なまえ／配慮／席）。自分が書き出したCSVはクリック0回で読み戻せる。
  違えば列ごとのプルダウンで直せる
- **書き出しは UTF-8 BOM 付き**（付けないと日本語Excelで文字化けする）。
  `CSVで保存`＝名簿と配慮、`この席ごとCSVで保存`＝それに席を足したもの、`ひな形CSV`＝書き方の見本
- **CSV / Excel 取り込み**（`#sk-csv`）: `FileReader` で ArrayBuffer として読み、UTF-8で復号して `�` が混ざれば **Shift_JIS で読み直す**
  （学校の名簿CSVはShift_JISが多い）。区切りは1行目のタブ数とカンマ数で判定。引用符つきセルに耐えるパーサを自前で持つ。
  なまえは**複数列えらべる**（姓と名が別列のとき両方えらぶと半角スペースで連結）。漢字かなが多い列を初期選択にする
- **前回の席を避ける**（`#sk-prev`）: 結果を「この席ごとCSVで保存」し、次回そのCSVを読ませる。
  「席」列から座席表を組み直し、`#sk-prev` で「前回と同じ席にしない」「前回と同じ隣にしない」を選べる。
  席の数も前回に合わせて設定する

## 席の決め方

- **座標**: `grid[r][c]`、`r` は前から（0が最前列）、`c` は黒板から見て左から
- **前列** = 各列の一番前の席、**後列** = 各列の一番後ろの席（`columnEdges()`。2026-10-04 に「前から2列目まで」から変更：2ばんに入ると前列に見えないため。席を足し引きした形でも列ごとに取る）
- **離す** = 周囲1マス（前後左右＋斜めの8マス）に入れない（2026-10-04 に斜めも含める形へ変更。FAQに明記）
- **隣** = 前後左右のどれかに座らせる（斜めは数えない）。置く時点で相手が座っていればその隣、まだなら相手が座れる空席が隣に残っている席だけを候補にする。
  並び順は相手がすぐ後ろに来るよう並べ替える（`withPartnersNext()`）。1人に「隣」が5人以上、離れた固定席どうしの「隣」は探索前にエラー
- **アルゴリズム**: ランダム再試行（最大4000回）。固定席を先に置き、次に**席の候補が狭い順**（前列・後列指定 → その他）に、
  その時点で「離す」に触れない空席へランダムに置く。全員置けたらその配置を返す
- **前回の席の回避は「守れなければ自動でゆるめる」**（`prevAttempts()`）。きつい順に
  「席も隣も避ける」→「隣だけ避ける」→「席だけ避ける」→「前回条件なし」を試し、通ったところで採用する。
  ゆるめたときは `#sk-msg` にその旨を出す（エラーにはしない）。2×2に4人のように**原理的に隣を避けられない**配置があるため、
  ここをエラーにすると使えなくなる
- **作れないときは理由を具体的に出す**（`diagnose()`）。席不足・固定席の重複／範囲外・前列や後列の定員超過・前後列の矛盾は
  探索の前に検出して数字つきで説明する。それ以外は探索失敗として「条件を1つ減らすか席を増やす」よう促す

- **挙動（E2Eで検証）**:
  - 「見本を入れる」で30人＋5つの配慮（離す・前列・後列・隣・固定）と性別が入る。配置は「配置する」を押したとき
  - **連続生成しても配慮が壊れない**（40回引き直して、離す2人が周囲1マスに入らない・隣2人が前後左右に並ぶ・前列指定が各列の一番前・後列指定が各列の一番後ろ・固定席が動かない・重複や取りこぼしがないことを確認済み）
  - エラー系はそれぞれ固有のメッセージになる（席不足／前列定員超過／固定席の重複／固定席が範囲外／名簿にない名前／書式ちがい／前後列の矛盾／探索失敗／名簿が空）
  - `#sk-out` はタブ区切りで、そのままExcelに貼れる
- **印刷**: `@media print` で座席表以外（ヘッダー・入力欄・説明・フッター）を隠す。**印刷ボタンはブラウザのダイアログを開く**ため、自動テストからは押さない
  - **CSVの往復**（2026-08-24にブラウザで確認済み）: 見本30人を「この席ごとCSVで保存」→ 画面を空にして読み戻すと、
    列の役割が**クリック0回で自動判別**され、名簿・配慮4種・前回の席・席の数がすべて復元される。
    そのまま20回引き直して、離す／前列／後列／固定の違反0件、**前回と同じ席0件・同じ隣0件**
    （固定席の子だけは同じ席になるが、これは固定指定どおり）。
    2×2に4人の原理的に不可能なケースでは、エラーにならず「同じ席にしない」だけ守って生成しメッセージが出る
- **操作の順番を見せる**（2026-10-04 ユーザー指摘「どの順番で操作したらわからない／オレンジボタンが多くて迷子」）:
  上に手順バー `#sk-stepbar`（見出し「つくる順番」と「いま 2／4：…」の進み具合つき。いまの手順はオレンジの塗り、終わった手順は緑の✓。1 座席の形を決める → 2 名簿と配慮を入れる → 3 配置する → 4 手直しして印刷）。
  形を確定していない＝1、確定して名前が空＝2、名前あり＝3、結果あり＝4。終わった手順は ✓。
  枠の見出しにも同じ番号。**オレンジで塗るボタンは手順ごとに1つ**（この形で確定する／配置する／結果の再配置する）。
  CSVで保存・名簿の上の配置する（`#sk-gen2`）は白い枠のボタン。タブ名は手順番号と紛れないよう番号を付けない
- **PC推奨**: ヒーローとランディングに「パソコンでの利用をおすすめします」。座席の形づくり（点線の席）は横に広く、スマホでは枠の中を横スクロールする
- **消す前の確認**: 名前か配慮が入っている行の ✕、名簿が入っているときの「見本を入れる」は `window.confirm` で確かめる（空の行は確認なしで消す）
- **名簿の行に席を出す**: 結果があれば各行の右に「3れつ 2ばん」。座席表が画面の外でも分かるように。入れかえ・再配置で更新し、形を変えて結果が消えたら消える
- **印刷**: どちらのタブを開いていても、結果があれば `beforeprint` で結果タブに切り替えて座席表を印刷する
- **手動確認観点**:
  - 「名簿はサーバーに送りません」の表示が消えていないか（このツールの前提そのもの）
  - 「消す」の確認ダイアログは `window.confirm`。**自動テストからは押さない**（ブラウザのモーダルで操作が止まる）
  - 印刷プレビューで座席表が1枚に収まるか（横の席数が多いクラスで確認）
  - 「離す」で斜めを許容していることが、FAQと実際の挙動で一致しているか
- **配慮を かくす**（2026-10-08）：結果の上に「配慮を かくす（電子黒板に うつすとき）」のチェック。固定・前列・後列の札と男女の色を消し、ふつうの席と同じ見た目にする。えらんだ状態は localStorage `sk-hide-care` に残す。印刷には もとから札を出していない
