# さんすう うちゅうたんけん さくらんぼざん（`tools/sakuranbo/index.html`）

- **目的**: さくらんぼ算（くり上がりのあるたし算）だけを4パターンで練習する（2026-09-28追加。カード #47）
- **作り**: さんすう うちゅうたんけん（[tools-sansu-app.md](tools-sansu-app.md)）と**同じ `js/sansu-app.js`・`css/sansu-app.css` を使う**。
  `<body data-sansu-mode="sakuranbo">` で専用モードに切り替わる。絵・背景・窓・あそびかた（10もんチャレンジ／とことん）・せいせきリセットは さんすう と同じ。
  画面の見た目の約束は [_common.md](_common.md) と CLAUDE.md の修行アプリの節に従う
- **タイトル**: H1 は「さんすう うちゅうたんけん さくらんぼざん」（さんすう に さくらんぼざん と足した名前。ユーザー決定）
- **メニュー**: 1段目＝**わけかた**（うしろを わける／まえを わける／まぜて とく）。2段目＝**かず**（1けた どうし／2けたも でる）＋スタート
- **4パターン**（大きいほうを10にし、小さいほうを分ける）
  - うしろ・1けた：8 + 3 → 3 を 2 と 1
  - まえ・1けた：4 + 8 → 4 を 2 と 2（大きい数は 6〜9）
  - うしろ・2けた：28 + 5 → 5 を 2 と 3（次の10＝30をつくる。大きい数の1の位は 2〜9）
  - まえ・2けた：5 + 28 → 5 を 3 と 2
  - まぜて とく：まえ と うしろ を半々で混ぜる
- **図**: さくらんぼは分ける数の真下。答えさせる玉（10をつくる数）は**もう一方の数の がわ**に置き、下に「28 と あわせて 30」。答えるまで「= ?」は出さない
- **答えさせるもの**: 10（次の10）をつくる数だけ（ユーザー決定。のこりの数や式のこたえは正解後に表示）
- **やりかた画面**: 8 + 5（うしろ）に加えて 4 + 8（まえ）の例を出す
- **保存**: localStorage `sakuranboProgress`（さんすう の成績とは分ける）
- **修行いちらん（`js/ninja-links.js`）には未掲載**（バナーの絵が無いため）
- **手動確認観点**: 4パターン×かずで、正解の印が「10をつくる数」に付くか／まえを わける ときに さくらんぼが まえの数の下に出るか
