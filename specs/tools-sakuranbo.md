# さんすう うちゅうたんけん さくらんぼざん（`tools/sakuranbo/index.html`）

- **目的**: さくらんぼ算（くり上がりのある たしざん・くり下がりのある ひきざん）を練習する（2026-09-28追加。カード #47。2026-10-02 ひきざんを追加）
- **作り**: さんすう うちゅうたんけん（[tools-sansu-app.md](tools-sansu-app.md)）と**同じ `js/sansu-app.js`・`css/sansu-app.css` を使う**。
  `<body data-sansu-mode="sakuranbo">` で専用モードに切り替わる。絵・背景・窓・あそびかた（10もんチャレンジ／とことん）・せいせきリセットは さんすう と同じ。
  画面の見た目の約束は [_common.md](_common.md) と CLAUDE.md の修行アプリの節に従う
- **タイトル**: H1 は「さんすう うちゅうたんけん さくらんぼざん」（さんすう に さくらんぼざん と足した名前。ユーザー決定）
- **メニュー**: さんすう と同じ**2段**（2026-10-02 ユーザー指示）。しゅるいカードは絵を使わず、**わける数を赤くして下に さくらんぼを ぶら下げた小さな式**（8 + 3 の 3 の下に🍒）を出す。並びは上から「ひきざん」→ 式 →「まえの すうじを わける」。
  - 1段目 もんだいの しゅるい（カード3枚を横1列。スマホでも3列）：
    たしざん（ちいさい ほうの すうじを わける）／ひきざん（まえ 13 − 8）／ひきざん（うしろ 13 − 4）。下に あそびかた
  - たしざんを1枚にした理由：まえを わけるか うしろを わけるかは「小さいほうを わける」の違いだけ。
    2けたで まえを わける（5 + 28）は教科書に出ない。**まえを わける 4 + 8 は ふつう（1けたどうし）にだけ まぜる**（2026-10-02 ユーザーと決定）。
    ひきざんは げんかほう・げんげんほう で やりかたが違うので2枚
  - 2段目 むずかしさ（1列・やさしい順）：ふつう＝1けた どうし／むずかしい＝2けたと 1けた／ちょうなんもん＝**100 きじゅん**
- **形**（10の かたまりを つくるのは大きいほう、分けるのは小さいほう）
  - たしざん ふつう：8 + 3 → 3 を 2 と 1、4 + 8 → 4 を 2 と 2 を まぜる ／ むずかしい：28 + 5（うしろだけ）
  - たしざん ちょうなんもん：2けた ＋ 2けた で こたえが**かならず100を こえる**。100を つくる（79 + 39 → 39 を 21 と 18、100 + 18 = 118）
  - ひきざん うしろ（げんげんほう）：13 − 4 → 4 を 3 と 1、13 − 3 = 10、10 − 1 = 9 ／ むずかしい：43 − 6
  - ひきざん まえ（げんかほう）：13 − 8 → 13 を 10 と 3、10 − 8 = 2、2 + 3 = 5 ／ むずかしい：43 − 8（43 を 10 と 33）
  - ひきざん ちょうなんもん：100を こえる数 − 2けた で こたえは100より小さい。100 まで ひく／100 を とりだす（132 − 94）
  - **同じ数どうし（7 + 7）は出さない**（どっちの 7 を わけるのか わからない。ユーザー指示）
  - **2 を わける問題は出さない**（1 と 1 の1通りしかなく、選択肢が作れない）
- **問いかけ**: 何のために分けるかまで書く（ユーザー指示）。
  たしざん「8 と あわせて 10 に なるように 5 を わけよう」／ひきざん うしろ「13 から ひいて 10 に なるように 4 を わけよう」／
  ひきざん まえ「10 から 8 を ひけるように 13 を わけよう」
- **図**: さくらんぼは分ける数の真下。**赤い実・緑の じく・葉っぱ1まい**（CSSで描く。2026-10-02）。玉は2つとも答えるので、片方だけ目立たせたり ゆらしたりしない。
  玉の下に「8 と あわせて 10」「13 から ひいて 10」「ここから 8 を ひく」。答えるまで「= ?」は出さない
- **答え**: **分ける2つの数**を選ぶ（「2 と 1」。ユーザー指示）。並びは玉の並び（図の左から）。
  選択肢は**すべて足すと元の数になる分け方**（7 なら 1 と 6・2 と 5…）。足しても元にならない組み合わせ（7 を 4 と 4）は出さない（2026-10-02 ユーザー指示）。
  分け方が3つ以下の数（3・4）は ボタンも2つ・3つ（3つのときは最後の1つを横いっぱい）
- **答えあわせの文**: 正解＝「8 + 2 = 10、10 + 1 = 11!」「13 − 3 = 10、10 − 1 = 9!」「10 − 8 = 2、2 + 3 = 5!」／まちがい＝「3 は 2 と 1 に わけるよ」
- **スマホ幅**: 3けたが出る ちょうなんもん は式を小さくして左へ寄せる（`.is-long`）。問いかけは1行に収まる大きさ
- **もどる**: さんすう と同じ。プレイから「メニューに もどる」「✕ とじる」で1段目まで戻る
- **やりかた画面**: 8 + 5（うしろ）に加えて 4 + 8（まえ）の例を出す
- **保存**: localStorage `sakuranboProgress`（さんすう の成績とは分ける）
