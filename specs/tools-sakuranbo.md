- **形**（大きいほうを10にし、小さいほうを分ける）
  - 1けた・うしろ：8 + 3 → 3 を 2 と 1 ／ 1けた・まえ：4 + 8 → 4 を 2 と 2（大きい数は 6〜9）
  - 2けた・うしろ：28 + 5 → 5 を 2 と 3 ／ 2けた・まえ：5 + 28 → 5 を 3 と 2（次の10をつくる。大きい数の1の位は 2〜9）
  - ちょうなんもん：38 + 25 → 25 を 2 と 23（うしろを分ける。1の位の和が10以上＝くり上がりあり、こたえは99まで）
  - ぜんぶ まぜる：1けた・2けた、まえ・うしろ を混ぜる（ちょうなんもんは含めない）
- **図**: さくらんぼは分ける数の真下。10をつくる玉（is-target）は**もう一方の数の がわ**に置き、下に「28 と あわせて 30」。答えるまで「= ?」は出さない
- **答え**: **分ける2つの数**を4択で選ぶ（「2 と 1」。ユーザー指示）。並びは玉の並び（うしろ＝[10をつくる数, のこり]、まえ＝[のこり, 10をつくる数]）。
  まちがいの選択肢は ほかの分け方＋足しても元の数にならない組み合わせ。**2 を 1 と 1 に分けるとき（9 + 2）も4つそろう**ことを総当たりで確認済み
- **答えあわせの文**: 正解＝「8 + 2 = 10、10 + 1 = 11!」（まえ は「2 + 8 = 10、…」）／まちがい＝「3 は 2 と 1 に わけるよ」
