  - たしざんを1枚にした理由：まえを わけるか うしろを わけるかは「小さいほうを わける」の違いだけ。
    2けたで まえを わける（5 + 28）は教科書に出ない。**まえを わける 4 + 8 は 1けたどうしの段（ちょうかんたん・かんたん・ふつう）にだけ まぜる**（2026-10-02 ユーザーと決定）。
    ひきざんは げんかほう・げんげんほう で やりかたが違うので2枚
  - 2段目 むずかしさ（さんすう と同じ**2列×3段**・列ごとに上から やさしい順・**6段**。2026-10-03 ユーザー決定。
    1列だと学校のノートPCでスタートが画面の下に はみ出す）：ちょうかんたん＝わける数が いつも 1／かんたん＝わける数が 2・3／
    ふつう＝1けた どうし ぜんぶ／すこしむずかしい＝2けたと 1けた／むずかしい＝2けた どうし・つぎの10／ちょうなんもん＝**100 きじゅん**。
    id は さんすう と同じ（vs・s・m・h・h2・l）。3段だったころの h2（2けたと 1けた）の せいせきは h へ移す
  - ちょうかんたん：9 + □（□ を 1 と のこり）／□ − 9（10 − 9 = 1）／11 − □（□ を 1 と のこり）
  - かんたん：8・7 + □／□ − 8・7／12・13 − □
  - むずかしい：38 + 25（25 を 2 と 23、こたえは100まで）／62 − 25（げんかほう 62 を 30 と 32、げんげんほう 25 を 2 と 23）
- **形**（10の かたまりを つくるのは大きいほう、分けるのは小さいほう）
  - たしざん ふつう：8 + 3 → 3 を 2 と 1、4 + 8 → 4 を 2 と 2 を まぜる ／ すこしむずかしい：28 + 5（うしろだけ）
  - たしざん ちょうなんもん：2けた ＋ 2けた で こたえが**かならず100を こえる**。100を つくる（79 + 39 → 39 を 21 と 18、100 + 18 = 118）
  - ひきざん うしろ（げんげんほう）：13 − 4 → 4 を 3 と 1、13 − 3 = 10、10 − 1 = 9 ／ すこしむずかしい：43 − 6
  - ひきざん まえ（げんかほう）：13 − 8 → 13 を 10 と 3、10 − 8 = 2、2 + 3 = 5 ／ すこしむずかしい：43 − 8（43 を 10 と 33）
  - げんかほう の さくらんぼの下の ことば：わける前は「10 から 8 を ひく」、わけたあとは「10 から 8 を ひいて、3 を たす」（旧「ここから 8 を ひく」は どこから ひくのか 分かりにくかった。2026-10-03 ユーザー指示）
  - ひきざん ちょうなんもん：100を こえる数 − 2けた で こたえは100より小さい。100 まで ひく／100 を とりだす（132 − 94）
  - **同じ数どうし（7 + 7）は出さない**（どっちの 7 を わけるのか わからない。ユーザー指示）
  - **2 を わける問題は出さない**（1 と 1 の1通りしかなく、選択肢が作れない）
- **問いかけ**: 何のために分けるかまで書く（ユーザー指示）。
  たしざん「8 と あわせて 10 に なるように 5 を わけよう」／ひきざん うしろ「13 から ひいて 10 に なるように 4 を わけよう」／
  ひきざん まえ「10 から 8 を ひけるように 13 を わけよう」
- **図**: さくらんぼは分ける数の真下。**赤い実・緑の じく・葉っぱ1まい**（CSSで描く。2026-10-02）。玉は2つとも答えるので、片方だけ目立たせたり ゆらしたりしない。
  玉の下に「8 と あわせて 10」「13 から ひいて 10」「ここから 8 を ひく」。答えるまで「= ?」は出さない
- **答え（1もん2だん。2026-10-02 ユーザー指示：たす作業まで正解に入れる）**:
  1. **わける**：分ける2つの数を選ぶ（「2 と 1」）。並びは玉の並び（図の左から）。
     選択肢は**すべて足すと元の数になる分け方**（7 なら 1 と 6・2 と 5…）。足しても元にならない組み合わせ（7 を 4 と 4）は出さない。
     分け方が3つ以下の数（3・4）は ボタンも2つ・3つ（3つのときは最後の1つを横いっぱい）。
     答えると さくらんぼの中身が埋まり、式に「= ?」が出る。**まちがえても正しい分け方を見せて②へ進む**
  2. **こたえ**：問いかけが「こたえは どれ?」に変わり、式の こたえ（11 など）を4択で選ぶ。10の かたまりを わすれた まちがい（1・21）も選択肢に まぜる
  - **①②の両方が合って せいかい**（★・COMBO・とことんの すすみ は1もん単位）
- **答えあわせの文**: ①のあと＝「そう! 3 は 2 と 1。つぎは こたえ!」／「3 は 2 と 1 に わけるよ。つぎは こたえ!」。
  ②のあと＝下の「解説」のとおり（わけかた から こたえ までの流れを ぜんぶ書く。ユーザー指示）。
  解説の欄は はじめから2行ぶんの高さを取り、答えた瞬間に画面が ずれないようにする
- **解説**: ②のあと、**選択肢の場所を 解説に入れかえる**（見出しは「ときかた」）。中身は「こたえは 11」＋ ①3 を 2 と 1 に わける ②8 + 2 = 10 ③10 + 1 = 11 ＋「つぎへ →」。
  **問題（中身の入った さくらんぼ と「= 11」）は見えたまま**にする（絵に重ねると見えなくなった。ユーザー指示）。
  **押すまで次へ進まない**（1.2秒で進むと読む前に消えていた）。まる・ばつ の絵は一瞬だけ出し、**まちがいの「おしい!」は出さない**（ユーザー指示）。
  下の1行の解説文は出さない（右の解説と同じになるため）。さんすう は これまでどおり自動で進む
