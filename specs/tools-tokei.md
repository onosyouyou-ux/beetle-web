# とけい修行（`tools/tokei/`）

- **目的**: アナログ時計の読み方を4択で練習する子ども向けの静的アプリ。小1〜2のつまずきどころに絞る
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける。既存の「おうちのかたへ・FAQ」は利用中の補助情報として残す
- ヒーローに時計学習の画像と「リファレンス」リンクを表示し、`landing.html` へ移動する
- **画面構成**: メニュー → プレイ（1セット10問）→ けっか（★3段階）。`#tk-app` に JS が描画する
- **といかた（2モード）**: `read`＝時計を見て時刻を4択／`find`＝時刻を読んで4つの時計から選ぶ。**どちらも4択**にしてある
  （針をドラッグさせる形は操作が難しく、自動テストもできないため採らない）
- **むずかしさ（4段階）**: ちょうど（60分きざみ）／30ぷん／5ふんきざみ／1ぷんきざみ。学校で習う順番に合わせている
- **ぷんの数字**: 文字ばんの外がわに 0・5・10…55 を出す／消すをチェックで切り替え。**長針と同じ青**で描き、
  「この数字は分」と結びつけられるようにする（`.tk-num-min`）

## 時計はSVGで描く（画像素材を持たない）

`clockSvg(h, m, size, showMinutes)` が viewBox 220×220 のSVG文字列を返す。短針は `h*30 + m*0.5` 度で**分ぶんも進む**
（3時50分の短針が4に近い、という本物の見え方を再現する。ここを省くと「短針が3を指しているのに3時50分」という嘘の時計になる）。

## 選択肢は「まちがえ方」で作る

正解のほかに、つまずきの型をそのまま選択肢にする。ランダムな時刻を並べても練習にならない。

- **はりの とりちがえ**: 長針と短針を入れかえた時刻（3:50 → 10:15）
- **すう字を そのまま ぷんに した**: 長針がさす数字を分として読む（50ぷん → 10ぷん）
- **みじかい はりの よみまちがい**: 時が±1ずれる
- **ぷんの よみまちがい**: 分が1きざみ分ずれる／左右反転する

まちがえたときは、選んだ選択肢に持たせた `why` をフィードバックに出す（「はりの とりちがえ」など）。

- **挙動（E2Eで検証）**:
  - `read` モード：時計SVGの針の角度から時刻を復元すると、必ず選択肢の中に正解の読みがある
  - `find` モード：問われた時刻の時計が4つの中に必ずあり、4つとも別の時刻になる
  - 「ふん／ぷん」の読み分けが1の位で正しく変わる（0ぷん 1ぷん 2ふん 3ぷん 4ぷん 5ふん 6ぷん 7ふん 8ぷん 9ふん）。
    10ぷん・15ふん・20ぷん・35ふん・50ぷん・55ふん が代表例
  - `m === 0` のときは「〇じ」と表示し、「〇じ0ふん」にはしない
- **手動確認観点**:
  - 短針が分ぶん進んでいるか（5ふんきざみで50分台の時計を出し、短針が次の数字の直前にあること）
  - ぷんの数字を消したときに、時計だけで読めるか
  - まちがえたときのフィードバックが、責める言い方になっていないか
