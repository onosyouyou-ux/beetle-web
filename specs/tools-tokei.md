# とけい修行（`tools/tokei/`）

- **目的**: アナログ時計の読み方を4択で練習する子ども向けの静的アプリ。小1〜2のつまずきどころに絞る
- **アプリ画面に置くのは あそびかた3ステップだけ**（2026-08-26）。おうちのかたへ・よくある しつもんはランディング（`landing.html` の `#for-family` と `#faq`）に集約し、アプリからはヒーローの「おうちのかたへ・よくある しつもん」ボタンと紙面下部の `.nk-doc-ref` で行く。紙面のいちばん下に `.nk-back-tools`（`/edu-tools.html#kids` へ戻る）を置く
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける。既存の「おうちのかたへ・FAQ」は利用中の補助情報として残す
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヒーロー＋盤面が1画面に収まる**こと（スクロールさせない）。ランディング側も同じ
- ヒーローに時計学習の画像と「リファレンス」リンクを表示し、`landing.html` へ移動する
- **画面構成**: メニュー → プレイ（1セット10問）→ けっか（★3段階）。`#tk-app` に JS が描画する
- **といかた（2モード）**: `read`＝「いま なんじ？」時計を見て時刻を4択／`find`＝「とけいは どれ？」時刻を読んで4つの時計から選ぶ。**どちらも4択**にしてある。
  **ラベルは「なにを聞かれるか」を問いの形でそのまま書く**（2026-09-12改定）。旧「とけいを よむ／とけいを さがす」は
  どちらも時計の話に見えて違いが伝わらなかった
  （針をドラッグさせる形は操作が難しく、自動テストもできないため採らない）
- **なんいど（5段階）**: ①みじかい はり／ながい はり（**同じ段の2つ**。1行に横並び）→ ②ちょうどの じかん（60分きざみ）→
  ③30ぷんきざみ → ④5ふんきざみ → ⑤1ぷんきざみ。②以降は学校で習う順番に合わせている。
  **「じかんのみ」は日本語として意味が取りにくいので 2026-08-26 に「ちょうどの じかん」へ改名**（note は「3じ・8じ など」）。
  **並列の選択肢ではなく段階**なので、広い画面では縦1列に積んで階段に見せる（2026-08-25決定）。
  ただし段が6つに増えたため、**高さが足りない画面（スマホ縦・寝かせた画面・ノートPC/iPad横）では2列に折り返す**
  （左→右の並びが やさしい→むずかしい なので順番は読める。2026-09-08）。
  段は配列の並び順ではなく `level` で持つ。手裏剣は行ではなく**ボタンごと**に持たせ、
  2列に折り返すときは `.tk-pair` を `display:contents` にして1つの流れに戻す
- **手裏剣のアイコン**: `assets/images/ninja/shuriken-on.webp`（オレンジ＝その段に届いている）と
  `shuriken-off.webp`（青＝まだ）の**絵2枚**。CSSで色を塗り分けるのではなく画像を差し替える
  （2026-09-09にインラインSVGから自作アイコンへ変更）。表示は 19px／スマホ16px／寝かせた画面13px、
  原本は 56px の透過WebP（もとの絵は 1254px のPNG。**2枚を共通の正方形に中央ぞろえしてから縮小**し、
  on/off で大きさがずれないようにしている）
- **はりを1本ずつ見る段（2026-09-08追加）**: 「どちらの針を見るか」と「長い針の数字を分に直す」を切り分けて練習させるための土台。
  - **みじかい はり**: 短針だけを描き「なんじ？」を4択。**分は 0〜55 でランダムに持たせ、短針を数字と数字のあいだに立てる**
    （ちょうどの位置しか出さないと本物の時計で役に立たない）。誤答には必ず 次の数字・前の数字 を混ぜる。
    外がわの「ぷん」の数字は手がかりにならないので、この段では出さない
  - **ながい はり**: 長針だけを描き「なんぷん？」を4択。**5ふんきざみに固定**する
    （1ぷんきざみは⑤にまかせ、ここは「12から5とびでかぞえる」だけに集中させる）
  - どちらも `read`／`find` の両モードに対応する
  - **秒針はやらない**（2026-09-08決定）。60めもりを数える練習が「ながい はり」と完全に重複し、
    秒を習うのは3年生でこのアプリの対象（小1〜2の時計の読み）の外側のため
- **ぷんの数字**: 文字ばんの外がわに 0・5・10…55 を出す／消すをチェックで切り替え。**長針と同じ青**で描き、
  「この数字は分」と結びつけられるようにする（`.tk-num-min`）

## 忍具の表示（2026-09-09）

- 難易度は紺色の四方手裏剣。未点灯は同じ絵をグレー・薄色で表示する。
- 回答カードは、くない・手裏剣・巻物・煙玉の順で目印を表示する。文字回答は左余白20px、48pxの忍具、間隔12px、左揃えの回答を縦中央に並べる。小画面は余白12px・忍具36px・間隔8px。
- 難易度・回答・正解数の手裏剣は45度回した「×」向きで統一する。
- 進行欄は巻物風の帯に「第○問 / 全10問」「できた！ ○問」と10個の進行印を表示する。
- 正解時は正解数を即時更新し、手裏剣が一度弾む。動きを減らす設定ではアニメーションを止める。
- 結果の「もういちど」は最大320px・中央寄せ。戻るボタンとは24px空け、結果文は暗い背景で読める生成り色にする。
- 素材は `assets/images/ninja/tokei-ui/` の透過WebPを使用する。

## 時計はSVGで描く（画像素材を持たない）

`clockSvg(h, m, size, showMinutes, hands)` が viewBox 220×220 のSVG文字列を返す。`hands` は `both`／`hour`／`minute` で、
描く針を選ぶ（なんいど①で使う）。短針は `h*30 + m*0.5` 度で**分ぶんも進む**
（3時50分の短針が4に近い、という本物の見え方を再現する。ここを省くと「短針が3を指しているのに3時50分」という嘘の時計になる）。

## 選択肢は「まちがえ方」で作る

正解のほかに、つまずきの型をそのまま選択肢にする。ランダムな時刻を並べても練習にならない。

- **はりの とりちがえ**: 長針と短針を入れかえた時刻（3:50 → 10:15）
- **すう字を そのまま ぷんに した**: 長針がさす数字を分として読む（50ぷん → 10ぷん）
- **みじかい はりの よみまちがい**: 時が±1ずれる
- **ぷんの よみまちがい**: 分が1きざみ分ずれる／左右反転する
- はり1本の段だけの型: **つぎの すう字を よんだ／まえの すう字を よんだ**（短針）、
  **ぎゃくむきに かぞえた／すう字 1つぶん ずれた**（長針）

まちがえたときは、選んだ選択肢に持たせた `why` をフィードバックに出す（「はりの とりちがえ」など）。

## ヒント（`hintLines()`）

こたえそのものは言わず、「どっちの はりを 見て、どう かぞえるか」だけを出す。

- **かけ算・わり算のことばを使わない**（2026-09-09決定）。対象は小1〜2で、まだ九九もわり算も習っていない。
  「5ばい する」「5で わる」ではなく **「12から 右まわりに 5・10・15… と 5とびで かぞえる」** と書く
- ボタン（`.tk-hint-btn`）は**盤面の下に全幅・中央**。開いたヒント（`.tk-hint`）も
  回答欄の下ではなく**問題欄と回答欄の両方の下に全幅**で出す（どちらの はりの話も入るため。2026-09-09）

- **挙動（E2Eで検証）**:
  - `read` モード：時計SVGの針の角度から時刻を復元すると、必ず選択肢の中に正解の読みがある
  - `find` モード：問われた時刻の時計が4つの中に必ずあり、4つとも別の時刻になる
  - 「ふん／ぷん」の読み分けが1の位で正しく変わる（0ぷん 1ぷん 2ふん 3ぷん 4ぷん 5ふん 6ぷん 7ふん 8ぷん 9ふん）。
    10ぷん・15ふん・20ぷん・35ふん・50ぷん・55ふん が代表例
  - `m === 0` のときは「〇じ」と表示し、「〇じ0ふん」にはしない
  - はり1本の段では、答えも選択肢も「〇じ」だけ／「〇ぷん」だけになる（`answerText()`）
- **手動確認観点**:
  - 短針が分ぶん進んでいるか（5ふんきざみで50分台の時計を出し、短針が次の数字の直前にあること）
  - ぷんの数字を消したときに、時計だけで読めるか
  - まちがえたときのフィードバックが、責める言い方になっていないか
  - **9サイズ（360x640／390x740／430x932／667x375／852x393／932x430／768x1024／1024x768／1440x900）で
    メニューの「スタート」まで1画面に入るか**。なんいどが6つになって余白が消えたので、
    ラベルや余白をいじったら必ず測り直す（2026-09-08 実測でPASS）
