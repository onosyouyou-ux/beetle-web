# さんすう うちゅうたんけん（`tools/sansu-app/index.html`）

- **目的**: 小学生・幼児向けの計算ドリル（サーバー不要の静的ツール）。たしざんを4段階の難易度で練習する
- **公開状態**: **開発中の未公開ページ**（2026-07-20時点）。サイト内リンクなし・`sitemap.xml` 未登録・`noindex, nofollow`。
  公開するときは noindex を外し、`landing.html` を作って canonical をそちらへ向け、sitemap に登録する
- **レイアウト型**: Tool系静的アプリ（[_common.md](_common.md)「アプリ紙面ルール」参照）。
  **レイアウトは縦1カラム固定**（2026-07-20決定）。コンテンツ列は640px、その外側は背景（星空タイル `bg-space.png`）で世界観を出す
- **画面構成**: メニュー（けいさんの しゅるい／むずかしさ／あそびかた を選んでスタート）→ プレイ → けっか
- **むずかしさ**: こたえの大きさで定義（5 / 10 / 20 / 100まで）。**学年は持たない**
  （算数では数の範囲がそのまま難易度で、学年と二重指定になるため。漢字を追加する場合は漢字モード固有の軸として持たせる）
- **あそびかた**: 10もんチャレンジ（けっか画面で星3段階）／とことん（100問区切り・最大1000問・累計保存）
- **保存**: localStorage `sansuProgress`（`version: 2`。モード追加に耐えるよう version 付き）
- **選択肢**: ありがちな間違い（±1・±2、こたえ20以上では繰り上がり忘れの±10）から生成し、消去法で解けないようにする
- **拡張余地**: ひきざん・さくらんぼざんは「じゅんびちゅう」枠のみ。さくらんぼ算は4択にならないため、
  モード定義で出題UIを差し替えられる構造にしてある
- **手動確認観点**: 実機での音（自動テストでは検証不可）／スマホ縦でのボタンの押しやすさ／
  とことんモードのステージクリア演出
