# さんすう うちゅうたんけん（`tools/sansu-app/index.html`）

- **目的**: 小学生・幼児向けの計算ドリル（サーバー不要の静的ツール）。宇宙探検の世界観で計算を練習する
- **公開状態**: **公開済み**（2026-07-24）。`edu-tools.html`「おうちで使えるツール」からランディング経由でリンク。
  アプリ本体は `noindex` を持たず、canonical / og:url は `landing.html` を指す（評価はランディングに集約）。sitemap には `landing.html` を登録（アプリ本体は未登録）
- **レイアウト**: 縦1カラム固定（2026-07-20決定）。**紙面（`.app-paper`）は PC 1100px / スマホ 560px**、その中のコンテンツ列は約940px。
  紙面の外側は宇宙の背景画像 `bg-space.jpg`（cover）。紙面枠・ボタン・板は支給素材を `border-image`（9スライス）で敷き、
  アイコンは PNG（`object-fit:contain`）を重ねる。文字はHTMLで重ねる（素材に焼き込まない＝ラベルを動的に変えられる）
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヘッダー＋もんだい盤が1画面に収まる**こと（スクロールさせない）。ランディング側も同じ。
  ※上の「縦1カラム固定」は 2026-08-25 時点の実装と食い違っている（タブレット横・PCでは もんだい と 選択肢 を左右2カラムで出している）。次に触るとき整理する
- **画面構成**: メニュー → プレイ → けっか
- **メニューは2段**（2026-10-01 ユーザー決定）: 1段目＝たしざん・ひきざん の2つ（押したら2段目へ）＋あそびかた（既定は10もんチャレンジ）＋せいせきリセット。
  2段目＝えらんだ しゅるい・あそびかた の表示＋むずかしさ6つ（2列。左上から右へ やさしい順）＋スタート＋「← たしざん・ひきざん に もどる」。
  むずかしさ は何も選んでいない状態で出し、選ぶまでスタートは押せない。プレイ・けっか の「メニューに もどる」は1段目へ。
  ※2026-09-30〜10-01 は「けたの形6つ → むずかしさ」だったが、形とむずかしさが入りまじって わかりにくかったため改めた
- **むずかしさ（6つ）**:

  | むずかしさ | たしざん | ひきざん |
  |---|---|---|
  | ちょうかんたん | こたえが5まで（2 + 3） | 5までの数から ひく（5 − 2） |
  | かんたん | こたえが10まで（4 + 5） | 10までの数から ひく（9 − 4） |
  | ふつう | 1けたどうし・くり上がりあり（8 + 5） | 11〜18 − 1けた・くり下がりあり（13 − 6） |
  | すこしむずかしい | 2けた＋1けた・くり上がりなし（23 + 5） | 2けた−1けた・くり下がりなし（25 − 3） |
  | むずかしい | 2けた＋1けた・くり上がりあり・こたえ99まで（27 + 6） | 2けた−1けた・くり下がりあり（23 − 5） |
  | ちょうなんもん | 2けた＋2けた・こたえ3けたもある（38 + 25） | 2けた−2けた（56 − 23） |

  - 2けたと1けた は、くり上がりなし＝すこしむずかしい → くり上がりあり＝むずかしい の順（2026-10-01 ユーザー指示）
  - ひきざんの こたえは0にしない
  - 出題は条件に合う組み合わせが出るまで引きなおす（`drawPair`。条件は `ADD_RULES`／`SUB_RULES`）
- **かけざん・わりざん・さくらんぼざんは ぬいた**（2026-09-30 ユーザー指示）。
  九九は [かけざん修行](tools-kuku.md)、さくらんぼ算は [さくらんぼざん](tools-sakuranbo.md) の専用アプリへ。わりざんは いまは無い
- **あそびかた**:
  - **10もんチャレンジ**: 10問。けっか画面は 1もんずつ せいかい★・まちがい☆ を10こ並べる（2026-09-23。星3段階から変更）
  - **とことん（太陽系ツアー）**: 毎回 **0スタート**（累計に依存しない）。**10問「正解」ごとに次の天体へ到着**し、
    全10星＝**100問正解でコンプリート**。進捗は正解数ベース（間違えても星は進まない）。
    航路はバーの上に配置（到達=点灯・現在地=拡大パルス・未到達=グレー）、スタート地点（地球）は大きな金色の★、
    到着時は「〇〇に とうちゃく!」を到着した惑星アイコンの上にバブル表示。天体は地球から近い順
    （つき→きんせい→かせい→すいせい→もくせい→どせい→てんのうせい→かいおうせい→ブラックホール→かがやくほし）
- **COMBO（連続正解）**: 2連続からヘッダー右に「🔥 COMBO ×N」を表示、正解でポップ・不正解でリセット・5連ごとにファンファーレ。
  けっか画面に「さいだい COMBO ×N」
- **出題**: `make()` が答え・選択肢・レイアウトを返す（4択以外のモードも追加できる構造）。
  **出題前に直近3問と重複チェック**して同じ問題の連続を避ける
- **選択肢**: ありがちな間違い（±1・±2、こたえ20以上では繰り上がり忘れの±10）から生成し、消去法で解けないようにする
- **もどるボタン**: プレイ画面では**一番下**（中央）に配置
- **素材**: `assets/images/sansu/` … `bg-space.jpg`（背景）／`buttons/`（板枠 choice-default・choice-selected・start-button・reset-button）／
  `icons/`（余白付き icons-padded 由来）／`route/`（惑星9種）。**地球スタートとゴールの星はアイコン未支給のため ★／絵文字（仮）**
- **保存**: localStorage `sansuProgress`（`version: 2`。モード追加に耐える）。とことんの進捗バーはセッション内（0スタート）だが、通算成績は記録
- **手動確認観点**: 実機での音（自動テスト不可）／スマホ縦でのボタンの押しやすさ／
  border-image の角・金具の歪み／とことんの到着バブルと★スタートの見え方
