# フォニックス修行（`tools/phonics/`）

- **目的**: 「ABCは言えるのに単語が読めない」を直す。原因は2つあり、両方を扱う
  1. 学校で覚えるのは文字の**名前**（エー・ビー・シー）で、読むのに要るのは**音**（ア・ブ・ク）
  2. 先に習ったローマ字が干渉する（`name` を「ナメ」、`cake` を「カケ」と読む）
- **中心の仕掛け**:
  - `oto` モードの選択肢に **その文字の「名前」をわざと混ぜる**（名前と音の混同がつまずきの正体なので、
    ここを外すとただのカタカナ当てクイズになる）
  - `mahou` モードの選択肢に **ローマ字読みをわざと混ぜる**（同上）
  - こたえあわせで毎回、名前と音のちがい／ローマ字読みとのちがい のどちらかに触れる一文を出す
- **アプリ画面に置くのは あそびかた3ステップだけ**（2026-08-26）。おうちのかたへ・よくある しつもんはランディング（`landing.html` の `#for-family` と `#faq`）に集約し、アプリからはヒーローの「おうちのかたへ・よくある しつもん」ボタンと紙面下部の `.nk-doc-ref` で行く。紙面のいちばん下に `.nk-back-tools`（`/edu-tools.html#kids` へ戻る）を置く
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける
- **メニュー下の読み物は解説エリアに置く**（2026-08-27）。しゅぎょう中も見えるので、迷ったら下を見て確かめられる。枠の装飾（アプリの背景画像＋マスコット＋アクセント色の枠線）は `ninja-kids.css` に一元化。カタカナ・ローマ字・フォニックスで共通
- **しゅぎょうが3つのアプリは 768px 以上でメニューを横3分割**（2026-08-27）。縦3段だとそのぶん盤面が下へ押されるため。スマホは3段ルールどおり1カラム
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヒーロー＋盤面が1画面に収まる**こと（スクロールさせない）。ランディング側も同じ
- **画面のH1は「フォニックスしゅぎょう」（かな表記）**。`title`・OGPは検索向けに「フォニックス修行」
- **3モード（1セット10問）**:
  - `oto`（もじの おと）: 文字を見せて 音 を4択（選択肢に文字の名前を1つ混ぜる）
  - `tsunage`（つなげて よむ）: `c - a - t` を見せて 単語 を4択（1文字だけ違う実在語）
  - `mahou`（まほうの e）: `name` などを見せて 読み を3択（正解／ローマ字読み／e も読んだ形）
- **読み上げ**: ブラウザの音声合成（`en-US`、rate 0.85）。えいごよんで！と同じ作り。
  こたえあわせで自動再生し、ボタンで聞き直せる。**音声が無い端末でも問題は解ける**（音は補助）
- **成績は保存しない**（localStorage も使わない）

## データ（`js/phonics-data.js`）

`window.PHONICS_DATA` が単一のデータ源。app 側はこの形しか知らない。

- `letters`: `{ l, oto（音のカタカナ近似）, name（文字の名前）, ex（例語）, ja }` の26文字。母音は短母音
- `cvc`: `{ w, ja, near: [1文字だけ違う実在語×3] }`。**near は必ず実在する語にする**（作り話の語を出さない）
- `mahou`: `{ w, yomi, romaji, eYomi, ja }`。`romaji` は「ローマ字読みしたらこうなる」誤読

**カタカナ近似について**: 英語の音をカタカナで正確に書けないことはFAQで明言している。
それでも書くのは「音があることに気づく」段階を優先するため。正確さは読み上げで担保する。
この方針を変えるなら、FAQの文言も同時に直すこと。

- **手動確認観点**:
  - `oto` の選択肢にその文字の名前が入っているか（つまずきの再現になっているか）
  - `mahou` の選択肢にローマ字読みが入っているか
  - 読み上げが出ない端末でも操作が止まらないか
