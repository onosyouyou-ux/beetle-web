# テスト技法ドリル（`tools/technique-drill/`）

- **目的**: テスト設計技法を「読んで知っている」から「手が動く」へ移すための演習。`test-techniques`（読む）に対する「使う」側の入口
- **レイアウト型**: Reference系（[_common.md](_common.md) 参照）＋インタラクティブ部
- **構成**: `#tool`（ドリル本体）→ `#howto`（使い方3ステップ）→ `#about`（4つの技法）→ `#faq`
- **出題**: `js/technique-drill.js` が**その場で仕様を組み立てて生成する**（固定の問題データを持たない）。1セット10問。「ぜんぶ」は4技法を順に割り当ててからシャッフル、技法を選んだ場合はその技法だけ
- **扱う技法と答えの決まり方**（全部その場で計算できるものだけ。採点に迷いが出ないため）:

  | 技法 | 出題の形 | 答え |
  |---|---|---|
  | 境界値分析 | 「M以上N以下の整数」→ 2値でとる値の組／2値・3値の件数 | 2値＝`M-1,M,N,N+1` の4件、3値＝`M-1,M,M+1,N-1,N,N+1` の6件 |
  | 同値分割 | 区分表 → ある値と同じ区分の値／有効同値クラスの数 | 区分の定義そのもの |
  | デシジョンテーブル | Yes/Noの条件n個／多値条件の混在 | `2^n`、多値なら各条件の取りうる値の数の積 |
  | ペアワイズ | 因子と水準 → 全網羅の件数／2因子間網羅の下限 | 全網羅＝水準数の積、下限＝**水準数が最大の2因子の積** |

- **誤答の作り方**: 「ありがちな間違い」を優先して混ぜる。境界値なら内側だけ取った組・3値との取りちがえ、デシジョンテーブルとペアワイズなら掛け算のところを足し算した数。足りない分は正解の近傍の数字で埋め、正解と重複しないようにする（`fillNumberOptions`）
- **解説（`why`）**: 1問ごとに必ず出す。**このツールの主眼は正誤ではなく解説**なので、生成した具体的な数字を解説文に埋め込む（「下で 0/1、上で 100/101 の4件」のように）
- **答えが割れる論点の扱い**: 2値／3値、全網羅／下限のように**流儀や条件で答えが変わるものは問題文で必ず明示する**。明示せずに出すと正解が一意にならない
- **結果画面**: 正解数と正答率、まちがえた問題（問題文＋解説）の一覧、技法カタログとペアワイズ生成器へのリンク。**成績は保存しない**
- **手動確認観点**:
  - 生成された選択肢に**正解と同じ値が2つ並んでいないか**（`fillNumberOptions` の重複除去）
  - 同値分割で「同じ区分の値」を問うとき、正解と設問の値が同じ数字になっていないか（区分幅が狭いケース）
  - 解説の数字が問題文の仕様と食い違っていないか（生成値を使い回しているので、片方だけ直すとズレる）
