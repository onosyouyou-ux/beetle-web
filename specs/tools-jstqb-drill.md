# JSTQB Foundation Level 練習問題（`tools/jstqb-drill/`）

- **目的**: ソフトウェアテスト技術者資格 Foundation Level の学習用ドリル。`qa-quiz`（用語）と `technique-drill`（技法）の上に乗る、資格対策の入口
- **レイアウト型**: Reference系（[_common.md](_common.md) 参照）＋インタラクティブ部

## ⚠️ 権利まわり（このページで最も重要な制約）

- **問題文・選択肢・解説はすべて自作**。試験団体が公開しているシラバス本文・学習の目的（LO）の文言・サンプル問題は**公開されていても転載しない**（シラバスの利用条件で、研修コースの土台としての利用以外は書面承認が必要とされているため）
- 章立てだけは現行シラバス v4.0 の6章に合わせる（章タイトルは事実の見出しとして参照）
- **`.jq-disclaimer` は必須要素**（テストでも検証）。非公式であること／団体と無関係であること／JSTQB・ISTQB が登録商標であること／問題は自作であることを明記する
- ページタイトル・見出しで「公式」「公認」と誤認させる表現を使わない。`title` と OGP には「非公式」を入れる
- 問題を追加・修正するときも、この方針を必ず守る

## 構成

- `#tool`（アプリ）→ `#howto`（使い方3ステップ）→ `#about`（試験の形式）→ `#faq`
- 出題データは `js/jstqb-data.js`、アプリは `js/jstqb.js`

## 問題バンク（`JSTQB_Q`）

- **124問**。内訳は 第1章22／第2章20／第3章16／第4章30／第5章24／第6章12
- 形式: `{ ch, q, o[4], a, why }`。`a` は正解の添字、`why` は解説（**正誤よりここが主眼**）
- `JSTQB_CHAPTERS` に章の `name` / `note` / `exam`（模試での出題数）を持つ。`exam` の合計は40

## 2つのモード

| | 章別モード | 模試モード |
|---|---|---|
| 問題数 | 10問（章から抽出） | 40問（`exam` の配分 8/5/4/11/9/3） |
| 時間 | 制限なし | 60分カウントダウン。0で自動採点 |
| 解説 | 1問ごとに即時 | **途中では出さない**（時間配分の練習にならないため）。採点後にまとめて |
| 操作 | 次へ進むのみ | 前へ／次へ、あとで見直す印、問題番号の一覧から任意の問へジャンプ、任意のタイミングで採点 |
| 結果 | 正答率＋まちがえた問題の見直し | 合否判定（26問）＋章別正答率のバー＋見直し |

- **選択肢は出題のたびに並べ替える**（`prepare()`）。答えの位置を覚えてしまわないよう、正解の中身を持ち回って並べ替え後の位置を引き直している
- 成績は保存しない（localStorage も使わない）

## 手動確認観点

- **`.jq-disclaimer` が消えていないか**（最優先）
- 模試の途中で正誤が漏れていないか（`is-correct` / `is-wrong` は章別モードでのみ付く）
- タイマーがメニューに戻ったあとも動き続けていないか（`stopTimer()` の呼び忘れ）
- 模試を中断→再開したときに前回の回答が残っていないか
- 章別モードで、章の収録数が10未満になった場合に落ちないか
- 問題を追加したら `a` の添字がずれていないか（選択肢の順を編集したときに起きやすい）
