# フォニックス修行 ランディング

- **目的**: 検索・教育ツール一覧から受けるSEO集客面。アプリ本体 `/tools/phonics/` への入口
- **レイアウト型**: 教育系Toolランディング（`/css/edu-app-landing.css` をかんじ・とけい・カタカナ・ローマ字と共用）
- **構成**: ヒーロー → 3つの修行 → 「ローマ字がじゃまをしている」→ 使い方 → FAQ → CTA
- **ヒーロー画像は未設定**。`.eal-hero-grid` を使わず1カラムで組んである（画像が来たら2カラムにするだけ）
- **訴求の軸**: 「ABCは言えるのに単語が読めない」の原因を名指しする。
  英会話・単語暗記として売らない（そこは大手が強い）。**日本の子がローマ字で干渉を受ける**という
  他社教材が扱っていない点に絞る
- **書かないこと**: 「これだけで英語が読める」式の断定。フォニックスは読みの入口であって全部ではない
- **手動確認観点**: CTAが `/tools/phonics/` へ向いていること／FAQがアプリ画面のFAQと同内容であること
