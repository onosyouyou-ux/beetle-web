# ダミーファイル生成ツール（`tools/test-content/`）

- **目的**: テストデータ・サンプルPDF/CSV/Excelをブラウザ内で生成する静的ツール
- **レイアウト型**: Tool系（本体配信の静的ツール。ランディングなしのためリファレンスボタンは置かない）
- **QA系ツールで実際にいちばん見られているページ**（2026-09-15時点で約65表示/週。CIの水増しを含まない実数）。
  ここを入口に他のツールへ送る役目があるので、**末尾の `.site-description` の導線を消さないこと**
- **画面のFAQとJSON-LDのFAQPageは同内容**（7問）。片方だけ直さない。
  2026-09-15まで **JSON-LDにだけFAQがあり画面には無い**状態だったので、画面側を追加して揃えた
- **正直に書くところ**: 動画・音声で再生できるのは WebM だけで、MP4・MOV・AVI・WMV・MP3・WAV・AAC は
  **サイズ確認用のダミー（再生不可）**。ページとFAQの両方でそう書く。ここを曖昧にすると
  「開けないファイルが作られた」という誤解になる
- **サイズ指定**はバイト単位でぴったり作る。「1KB＝1024B／1000B」を切り替えられる（2026-09-17に旧「以上／未満」＝±10%を廃止。境界値テストに使えなかったため）。
  Excel・Word は本文を少なめに作り、足りないぶんをZIPのコメント欄で埋めて合わせる（形式の最小サイズ未満は作れない）
- **境界値セット**（`#bdBoundary`・`js/test-content-boundary.js`。2026-09-17追加）: アップロード制限の値を入れると
  「1つ少ない・ちょうど・1つ多い」をZIPで出す。タブは4つ
  - 容量：バイト単位。0バイトも任意で追加。合計512MB超はZIPにせず1つずつ保存
  - 画像の大きさ：幅・高さ・dpi のうち入れた値ごとにその値だけを±1。PNGは pHYs、JPEGは JFIF の密度欄に dpi を書く。
    1辺16,384px超はブラウザで作れないので外して注意を出す
  - ファイル名・拡張子：文字数／UTF-8バイト数、拡張子を含む／含まない。意地悪な名前18個＋中身と拡張子が違うファイル7個。
    **Windowsで使えない記号（\\ / : * ? " < > |）と予約名は入れない**（ZIPごと展開できなくなる）。ZIP内に「一覧.txt」
  - 長さ・件数：同時アップロード枚数（枚数ごとのフォルダ）・PDFページ数・CSV/Excel行数（見出し行を数えるか選べる）・
    音声の長さ（**再生できるWAV**。動画の再生時間はブラウザで正確に作れないので対象外と正直に書く）
- **生成物の検算**（2026-09-17実施）: 全形式で指定バイト数と一致／画像の px と dpi（pHYs・JFIF）／PDFの xref 位置／
  WAVの再生時間（decodeAudioData）／CSV・Excelの行数／ファイル名の文字数を、ブラウザ上で独立に数えて確認した
- **手動確認観点**: 生成ファイルが各形式で正しく開けるか／文字コード（CSVのBOM等）／
  FAQの開閉／`.site-description` のリンク先が全部生きているか
