# ローマ字修行 ランディング

- **目的**: 検索・教育ツール一覧から受けるSEO集客面。アプリ本体 `/tools/romaji/` への入口。
  ローマ字は小3で習うため、**9〜10月に検索が伸びる**想定（カタカナ修行と同じ季節性）
- **レイアウト型**: 教育系Toolランディング（`/css/edu-app-landing.css` をかんじ・とけい・カタカナと共用）
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う。スマホでは**ヒーロー画像を画面の高さから決めた帯**にし、
  **カードの絵と番号は同じ行**に置く（1カラムに折り返したときに大きな塊・余分な改行を作らない）
- **構成**: ヒーロー → 3つの修行 → つまずきやすい3点（っ・ん・のばす音）→ 使い方 → FAQ → CTA
- **おうちのかたへ（`#for-family`）**: アプリ画面から移した大人向けの説明3つ。FAQもアプリ側の設問を取り込み済み（2026-08-26）
- **ヒーロー画像は未設定**。`.eal-hero-grid` を使わず1カラムで組んである（画像が来たら2カラムにするだけ）
- **訴求の軸**: 「ローマ字の書き方が70年ぶりに変わった（2025-12-22の内閣告示でヘボン式が基本／2026年度からの指導もヘボン式）。
  でも上の学年とおうちのかたは訓令式で習っている」。ローマ字表を配るだけの既存教材が説明していない部分をここに置く。
  タイピング速度の練習として売らない（そこは既存サービスが強い）。**「学校＝訓令式」と書かない**（2026-09-04に全面差し替え）
- **FAQの先頭は「ローマ字がヘボン式に変わったというのは本当ですか？」**。改定の検索需要をここで受ける。
  JSON-LD の FAQPage も同内容にすること
- **手動確認観点**: CTAが `/tools/romaji/` へ向いていること／FAQがアプリ画面のFAQと同内容であること
