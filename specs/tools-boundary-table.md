# 境界値テスト表メーカー（`tools/boundary-table/`）

- **目的**: 下限・上限と「以上／より大きい」「以下／未満」から、境界値分析と同値分割のテストケース表を作る静的ツール（2026-09-17追加。板のアイデアカード「境界値・同値分割の表メーカー」）
- **レイアウト型**: Reference系（[_common.md](_common.md) 参照）＋インタラクティブ部。組み方は `test-dates` と同じ
- **構成**: `#tool`（テスト表を作る）→ `#why`（境目でまちがえる理由）→ `#faq`（6問。画面とJSON-LDは同内容）
- **位置づけ**: テスト技法カタログ（読む）↔ このツール（使う）↔ テスト技法ドリル（練習）。実データは ダミーファイル生成の境界値セット・意地悪な日付ジェネレーターへ送る
- **入力**: 項目はいくつでも足せる（`#bt-items` に `<template id="bt-item-tpl">` を複製）。型は 整数／小数（刻みを指定）／文字数／日付。例ボタン5つ（年齢・パスワード・数量・割引率・予約日）
- **芯（変えると意味が消える）**:
  - **小数は刻みの桁数で整数に直して数える**（0.1+0.2 の誤差を出さない）。日付はエポックからの日数の整数
  - 3値＝境界の1つ手前・ちょうど・1つ先。**2値＝有効と無効が入れかわる境目をはさむ2点**（「以上」なら 17/18、「より大きい」なら 18/19）
  - 同値クラスの代表値は、範囲のまん中と、境界から刻み10個ぶん離れた外側
  - **仕様で決まっていないことが多い値は期待結果を「要確認」で出す**（全角数字・前後の空白・先頭ゼロ・刻みより細かい小数・指数表記・絵文字の文字数・区切りちがいの日付など）。決めつけて「無効」にしない
  - 数直線は有効（緑）と無効（赤）を並べ、入れかわる所に線を引く。境界値は実線、同値クラスは点線
  - 条件がおかしいとき（有効な値が1つもない・下限も上限もない・日付の形式ちがい）は項目の下にエラーを出し、その項目だけ表から外す
- **書き出し**: Markdown（表示用の列）／TSV（Excelに貼る）／CSV（ダウンロードは UTF-8 BOM 付き）。TSV・CSV には「入力する文字列」の列があり、文字数の型では実際の文字列（1234567890の繰り返し）が入る
- **検算（2026-09-17）**: 18以上65以下／より大きい・未満 × 3値・2値、小数（0〜100・刻み0.05）、文字数（8〜20）、日付（2028-03-01〜03-31。うるう年の2月29日が下限の手前に出る）、下限だけ／上限だけ／1〜1、エラー2種をブラウザで数え直して確認。390px幅で横スクロールなし
- **レイアウトの注意**: body が flex なので、`.sw{min-width:0;width:100%}` を入れないと表と数直線の最小幅でページごと横にはみ出す（実際に踏んだ）
