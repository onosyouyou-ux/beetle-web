# かんじドリル（`tools/kanji/`）

- **目的**: 学年別漢字配当表にもとづく漢字を4択で練習する子ども向けの静的アプリ
- **収録範囲**: **小1（80字）・小2（160字）の240字**。1026字すべては入れていない。
  範囲は画面上（`.kj-scope`）とFAQに明記し、「学年別」とだけ書いて全学年あるように見せない
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  ランディングを持たないため canonical は自分自身
- ヒーローに学習イメージ画像と「リファレンス」ボタンを表示し、アプリ内モーダルで3ステップ・2つの練習モード・収録範囲を確認できる
- **画面構成**: メニュー → プレイ（1セット10問）→ けっか（★3段階＋**まちがえたことばの一覧**）
- **といかた（2モード）**: `yomi`＝ことばを見て よみ を4択／`kanji`＝よみ を聞いて ことば を4択
- **がくねん**: 小1／小2／ぜんぶ。**`GRADES` はデータから自動で組み立てる**ので、
  データに `g:3` を足せばメニューに「小3ねん」が自動で増える（app 側の変更は不要）
- **成績は保存しない**（localStorage も使わない）。まちがえたことばはその回のけっか画面にだけ出す

## データ（`js/kanji-data.js`）

`window.KANJI_DATA` に `{ g: 学年, k: 漢字, w: [[ことば, よみ], ...] }` の配列を置く。app 側はこの形しか知らない。

**データの決まり（機械検証できる形にしてある）**

1. 漢字に重複がない
2. どの `ことば` にもその `k` が含まれている
3. `よみ` はひらがな（と長音符）だけ
4. **`ことば` に使う漢字は、その学年までの配当漢字だけ**。それより上の字はひらがなで書く
   （例：小1の「名まえ」「校てい」／小2の「心ぱい」「番ごう」）

学年を足すときは、この4つを満たすように追記する。

## 選択肢の作り方

- **`yomi` モード**: ①同じ漢字の別のことばの よみ（音と訓の取りちがえ。「走り出す」に対する「はしる」）→
  ②同じ学年の、よみの長さが近いことば の よみ、の順に詰める
- **`kanji` モード**: 同じ漢字を使うことば・同じ字数のことばを優先する。
  **よみが正解と同じことばは候補から外す**（「ひ」に対して 日 と 火 が並ぶと正解が2つになってしまうため）

- **挙動（E2Eで検証）**:
  - 選択肢は常に4つで、重複がない
  - `yomi` モード：出題されることばは選んだ学年のもので、その正しい よみ が必ず選択肢にある。選択肢はすべて実在の よみ
  - `kanji` モード：**正解がちょうど1つ**。選択肢はすべて選んだ学年のことば
  - 5通り（小1×2モード・小2×2モード・ぜんぶ×かんじ）× 60問をサンプルして上記が崩れないことを確認済み
- **手動確認観点**:
  - 収録範囲（小1・小2の240字）が画面とFAQの両方に書かれているか
  - 「書き取りはやらない」方針の説明が残っているか（紙に書く練習のほうが身につくため、あえて扱わない）
  - まちがえたことばの一覧が、責める見せ方になっていないか
