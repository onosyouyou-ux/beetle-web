# かんじ修行（`tools/kanji/`）

- **目的**: 学年別漢字配当表にもとづく漢字を4択と手書きで練習する子ども向けの静的アプリ
- **収録範囲**: **小1（80字）・小2（160字）の240字**。1026字すべては入れていない。
  範囲は**メニューのがくねん選択肢**（「小1で ならう かんじ／80じ」のように字数を添える）と、
  ランディングのFAQに明記し、「学年別」とだけ書いて全学年あるように見せない
  （2026-08-26にヒーローの `.kj-scope` バッジは廃止。選択肢そのものが範囲を示すため）
- **アプリ画面に置くのは あそびかた3ステップだけ**（2026-08-26）。おうちのかたへ・よくある しつもんはランディング（`landing.html` の `#for-family` と `#faq`）に集約し、アプリからはヒーローの「おうちのかたへ・よくある しつもん」ボタンと紙面下部の `.nk-doc-ref` で行く。紙面のいちばん下に `.nk-back-tools`（`/edu-tools.html#kids` へ戻る）を置く
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヒーロー＋盤面が1画面に収まる**こと（スクロールさせない）。ランディング側も同じ
- ヒーローに学習イメージ画像と「リファレンス」リンクを表示し、`landing.html` へ移動する
- **画面構成**: メニュー → プレイ（1セット10問）→ けっか（★3段階＋**まちがえたことばの一覧**）
- **といかた（3モード）**: `yomi`＝「かんじを よむ しゅぎょう」（ことばを見て よみ を4択）／
  `kanji`＝「かんじに する しゅぎょう」（よみ を聞いて ことば を4択）／
  `kaki`＝「かんじを かく しゅぎょう」（よみ を見て手書き → 自己採点。2026-09-12追加）。
  **ラベルは「よみかた／かんじ」の2語では何をするか伝わらなかったため、動作で言い切る**（2026-08-26）

## かく しゅぎょう（`kaki`・2026-09-12）

- **筆跡の自動判定はしない**。書いたあと正解を出して、子どもが「かけた／かけなかった」を自分で選ぶ。
  自動判定は「合っているのに ×」が必ず出て、そこで手が止まるため**あえて置かない**
- **出題はことばごと出し、その字だけを `○` で伏せる**（`大きい` → `○きい`／よみ `おおきい`）。
  「だい」だけでは 大・台・第 のどれか決まらないため
- **1問2タップ**（はんてい → かけた／かけなかった）。「つぎのもんだいへ」は置かず、
  まるをつけた時点で ○× の全面フィードバックを出して自動で次へ進む。
  待ち時間は `js/kanji.js` の **`NEXT_DELAY`（既定 2000ms）1か所**で決める
- **まるつけボタンは「ぜんぶ けす／はんてい」と同じ行に置きかえる**。盤面は
  `height:var(--nk-board-h)` ＋ `overflow:hidden` の固定枠なので、行を増やすとボタンが切られる
- **手書きパッドの大きさは `--kj-pad-h` の1本で管理する**（`css/kanji.css`）。段ごとに px を直書きしない。
  2カラムの段は `calc(var(--nk-qh) - var(--nk-tap) - 14px)`、1カラムの段と寝かせた画面は `dvh` で決める
- 田の字の目安線は **CSSの下地**で描く（canvas は線だけを持ち、「ぜんぶ けす」でマス目が消えないように）
- `touch-action:none`（無いとタブレットで書こうとするとページがスクロールする）と
  `devicePixelRatio` ぶんの拡大（無いと線がぼやける）は必須
- **縦持ちは、はんてい後の正解パネルを「大きい字＋右にことば」に組みかえる**。
  縦に3行積むと問題パネルが伸びて1画面から はみ出す（実測）
- **がくねん**: 小1／小2／ぜんぶ。**`GRADES` はデータから自動で組み立てる**ので、
  データに `g:3` を足せばメニューに「小3ねん」が自動で増える（app 側の変更は不要）
- **成績は保存しない**（localStorage も使わない）。まちがえたことばはその回のけっか画面にだけ出す

## データ（`js/kanji-data.js`）

`window.KANJI_DATA` に `{ g: 学年, k: 漢字, w: [[ことば, よみ], ...] }` の配列を置く。app 側はこの形しか知らない。

**データの決まり（機械検証できる形にしてある）**

1. 漢字に重複がない
2. どの `ことば` にもその `k` が含まれている
3. `よみ` はひらがな（と長音符）だけ
4. **`ことば` に使う漢字は、その学年までの配当漢字だけ**。それより上の字はひらがなで書く
   （例：小1の「名まえ」「校てい」／小2の「心ぱい」「番ごう」）

学年を足すときは、この4つを満たすように追記する。

## 選択肢の作り方

- **`yomi` モード**: ①同じ漢字の別のことばの よみ（音と訓の取りちがえ。「走り出す」に対する「はしる」）→
  ②同じ学年の、よみの長さが近いことば の よみ、の順に詰める
- **`kanji` モード**: 同じ漢字を使うことば・同じ字数のことばを優先する。
  **よみが正解と同じことばは候補から外す**（「ひ」に対して 日 と 火 が並ぶと正解が2つになってしまうため）

- **挙動（E2Eで検証）**:
  - 選択肢は常に4つで、重複がない
  - `yomi` モード：出題されることばは選んだ学年のもので、その正しい よみ が必ず選択肢にある。選択肢はすべて実在の よみ
  - `kanji` モード：**正解がちょうど1つ**。選択肢はすべて選んだ学年のことば
  - 5通り（小1×2モード・小2×2モード・ぜんぶ×かんじ）× 60問をサンプルして上記が崩れないことを確認済み
- **手動確認観点**:
  - 収録範囲（小1・小2の240字）が、メニューの選択肢とランディングのFAQに書かれているか
  - **かくモードが「自己採点であって、筆跡を判定するものではない」と分かる説明になっているか**
    （ランディングのFAQ・特徴、アプリの あそびかた3ステップ。2026-09-12に「書き取りは扱いません」から改定）
  - 手書きパッドが 9サイズ × はんてい前後 で1画面に収まり、盤面からボタンがはみ出していないか
  - まちがえたことばの一覧が、責める見せ方になっていないか
