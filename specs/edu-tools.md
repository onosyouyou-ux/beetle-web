# 教育支援メインページ（`edu-tools.html`）

- **目的**: 教育事業のメインページ。教育分野の受託とおうち・先生向けツールの入口
- **レイアウト型**: LP型（[_common.md](_common.md)「LP型」参照）。CSSは test-tools.css を流用し edu-tools.css で温かいオレンジに上書き
- **主な構成**: 01 教育分野でできること（アプリ制作・コンテンツ制作・PTA向けページ制作）→ 02 おうちのかたがつかうツール（えいごよんで・ルビメーカー）→ 03 お子さんがつかうツール（さんすう・とけい・かんじ・カタカナ・ローマ字・フォニックス）→ 04 先生向けツール（学級通信・席替え・班分け・所見）→ お問い合わせCTA
- **ツールの分け方（2026-08-25決定）**: 「**だれが手を動かすか**」で分ける。親が操作するもの（写真を撮る・文章を貼る）は 02、子どもが自分でタップして遊ぶものは 03。
  同じ「おうちで使う」でも使う場面が別物なので、1つのグリッドに混ぜない
- **固定ルール**:
  - カードのリンク表示・SPアコーディオンは [_common.md](_common.md)「カード・リンク共通ルール」に従う
  - 02・03・04 のツールカードは先頭に 16:9 のサムネイル（`.tool-thumb`、画像は `/assets/images/edu-thumbs/`。**1200×675 の JPG・150〜230KB 目安**。PNG原寸のまま置くと1ページ19MBになった失敗あり）を置く。サムネイル付きカードではのぞき丸アイコン（`.service-peek`）を出さない
- **手動確認観点**: ツールカードのリンク先（ランディング経由かアプリ直か）が方針どおりか／トーンがQA側と作り分けられているか／SPで▼開閉が動くか
