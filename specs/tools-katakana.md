# カタカナ修行（`tools/katakana/`）

- **目的**: 「どの ことばを カタカナで 書くのか」が分からず、文の中で「ぱん」「てれび」とひらがなで書いてしまう
  つまずきを消す子ども向けの静的アプリ。字形の練習ではなく**語の判断**が中心
- **中心の仕掛け**: 正解でもまちがいでも、答え合わせに**「なぜ カタカナで 書くのか」を一文（`hint`）で必ず出す**。
  ここを削ると、ただの4択クイズになりツールの意味が消える
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける
- **画面のH1は「カタカナしゅぎょう」（かな表記）**。小1が読めるようにするため。`title` と OGP は検索向けに「カタカナ修行」
- **3モード（1セット10問）**:
  - `dotchi`（どっちで かく？）: 語を見せて カタカナ／ひらがな の2択。半分ずつ `words` と `wago` から出す
  - `naosu`（カタカナに なおす）: ひらがなを見せて 正しいカタカナ表記を4択
  - `nigata`（にた字 みつけ）: シ/ツ・ソ/ン・ク/ワ・ス/ヌ・ケ/ク・ロ/コ を大きく出して2択
- **成績は保存しない**（localStorage も使わない）。まちがえた語とその理由はその回のけっか画面にだけ出す

## データ（`js/katakana-data.js`）

`window.KATAKANA_DATA` が単一のデータ源。app 側はこの形しか知らない。

- `words`: `{ w: カタカナ表記, k: ひらがな読み, c: 分類キー, hint: なぜカタカナかの一文 }`
- `wago`: `{ k: ひらがな表記, hint: なぜひらがな（漢字）かの一文 }`
- `nigata`: 形の似た字のペアと、書く向きでの見分け方
- **語を足すときは `hint` を必ず書く**（理由が出せない語は入れない）
- **分類は4つに絞る**（外来語・外国の国や人の名前・音や鳴き声・生き物の名前）。増やすと子どもが覚えられない
- **擬態語（ぴかぴか・ふわふわ）は入れない**。ひらがな表記がふつうで教科書でも割れており、
  「どちらでもよい」語を出すとルールが濁る。入れるのは音・鳴き声（ワンワン・ガタンゴトン）だけ

## まちがい選択肢の作り方（`naosu`）

「その子がほんとうに書きそうなまちがい」から順に選ぶ。ねらいの強い順に5段：

1. 形の似た字の入れかえ（シ↔ツ・ソ↔ン・ク↔ワ・ス↔ヌ・ロ↔コ）
2. のばす音「ー」を母音の字にしてしまう（ケーキ→ケエキ）
3. ちいさい字を大きく書いてしまう（コップ→コツプ）
4. だくてん・はんだくてんの付けまちがい（ジ→シ）
5. となりの字の入れかえ（ブラジル→ブラルジ）

- **ちいさい字と「ー」は 5 の対象から外す**。動かすと「ャニーニャー」のようなありえない並びができる
- どれも作れないときだけ、最後に同じ字数の別の語で埋める（ほぼ起きない）

- **手動確認観点**:
  - 答え合わせに理由の一文が毎回出ているか（ここが消えていないか）
  - `naosu` の選択肢が「別の語」ではなく「書きまちがい」になっているか
  - けっか画面の見出しが `nigata` のときだけ「まちがえた 字」になっているか
