# カタカナ修行（`tools/katakana/`）

- **目的**: 「どの ことばを カタカナで 書くのか」が分からず、文の中で「ぱん」「てれび」とひらがなで書いてしまう
  つまずきを消す子ども向けの静的アプリ。字形の練習ではなく**語の判断**が中心
- **中心の仕掛け**: 正解でもまちがいでも、答え合わせに**「なぜ カタカナで 書くのか」を一文（`hint`）で必ず出す**。
  ここを削ると、ただの4択クイズになりツールの意味が消える
- **アプリ画面に置くのは あそびかた3ステップだけ**（2026-08-26）。おうちのかたへ・よくある しつもんはランディング（`landing.html` の `#for-family` と `#faq`）に集約し、アプリからはヒーローの「おうちのかたへ・よくある しつもん」ボタンと紙面下部の `.nk-doc-ref` で行く。アプリ一覧へは1枚目の画面の盤面の下「← アプリいちらんに もどる」から戻る（2026-09-24に紙面下の `.nk-back-tools` を廃止。行き先が同じで重複していたため）
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける
- **メニュー下の読み物は解説エリアに置く**（2026-08-27）。しゅぎょう中も見えるので、迷ったら下を見て確かめられる。枠の装飾（アプリの背景画像＋マスコット＋アクセント色の枠線）は `ninja-kids.css` に一元化。カタカナ・ローマ字・フォニックスで共通
- **しゅぎょうが3つのアプリは 768px 以上でメニューを横3分割**（2026-08-27）。縦3段だとそのぶん盤面が下へ押されるため。スマホは3段ルールどおり1カラム
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヒーロー＋盤面が1画面に収まる**こと（スクロールさせない）。ランディング側も同じ
- **画面のH1は「カタカナしゅぎょう」（かな表記）**。小1が読めるようにするため。`title` と OGP は検索向けに「カタカナ修行」
- **4モード（1セット10問）**:
  - `dotchi`（どっちで かく？）: **例文の中に置いた語**を見せて カタカナ／ひらがな の2択。半分ずつ `words` と `wago` から出す。
    **語を単体で出さない**（「かぜ」だけでは どちらで書くか決められない。「かぜが ふく」の形にして、あてはめる語に下線を引く。2026-08-26）。
    答え合わせでも同じ例文を、正しい書き方（カタカナ／ひらがな）で見せる
  - `naosu`（カタカナに なおす）: ひらがなを見せて 正しいカタカナ表記を4択
  - `nigata`（にた字 みつけ）: シ/ツ・ソ/ン・ク/ワ・ス/ヌ・ケ/ク・ロ/コ を大きく出して2択。
    **選択肢は ひらがなだけ**（`そ`／`ん`）にする（2026-09-14）。カタカナを並べると、問題の字と選択肢の字を
    形で見くらべるだけで正解できてしまい、読めるかの確認にならない。答え合わせでは `ka`/`kb`（`ソ（そ）`）を出す
  - `kaku`（カタカナを かく）: **ひらがな1字**を見せて、カタカナ1字を手書きする（2026-09-14）。
    **筆跡の自動判定はしない**。合っているのに × が出ると そこで手が止まるため、「はんてい」でお手本を出し、
    子どもが自分で「かけた／まちがった」を押す（ローマ字修行の `kaku` と同じ作法）。
    出題は `moji`（清音46・濁音/半濁音25・ちいさい字4 の計75字）から10字。
    **「ー」は入れない**。ひらがなに対応する字がなく「ひらがなを見てカタカナを書く」形にならないため。
    のばす音のまちがい（ケーキ→ケエキ）は `naosu` のまちがい選択肢であつかう。
    説明文は二重に持たない。形の似た字は `nigata` の `hint` を、それ以外は `g`（分類）から app 側が組み立てる
- **しゅぎょうが4つになったのでメニューは 768px 以上で 2×2**（2026-09-14）。`ninja-kids.css` の
  `:has(>:nth-child(4))` が枚数から寸法を決めるため、CSS の追加は不要
- **成績は保存しない**（localStorage も使わない）。まちがえた語とその理由はその回のけっか画面にだけ出す

## データ（`js/katakana-data.js`）

`window.KATAKANA_DATA` が単一のデータ源。app 側はこの形しか知らない。

- `words`: `{ w: カタカナ表記, k: ひらがな読み, c: 分類キー, ex: 例文, hint: なぜカタカナかの一文 }`
- `wago`: `{ k: ひらがな表記, ex: 例文, hint: なぜひらがな（漢字）かの一文 }`
- **`ex` は `{}` を語の入る場所にした短い例文**（`'{}が ふく'`）。まわりの文はぜんぶ ひらがなで書く。
  app 側が `{}` に語をあてはめ、その部分に下線を引く
- `nigata`: 形の似た字のペアと、書く向きでの見分け方。`ka`/`kb` は答え合わせ用（`ソ（そ）`）、`ha`/`hb` は選択肢のひらがな
- `moji`: `{ h: ひらがな, k: カタカナ, g: 分類（省略=清音 / daku / handaku / small） }`。`kaku` で使う
- **語を足すときは `hint` と `ex` を必ず書く**（理由が出せない語は入れない）
- **`ex` は「その子が家でやること」を書く**。道具は使い道をそのまま書く
  （フォーク＝「たべる」。「さす」は物騒に読めるので使わない。2026-09-09修正）
- **分類は4つに絞る**（外来語・外国の国や人の名前・音や鳴き声・生き物の名前）。増やすと子どもが覚えられない
- **擬態語（ぴかぴか・ふわふわ）は入れない**。ひらがな表記がふつうで教科書でも割れており、
  「どちらでもよい」語を出すとルールが濁る。入れるのは音・鳴き声（ワンワン・ガタンゴトン）だけ

## まちがい選択肢の作り方（`naosu`）

「その子がほんとうに書きそうなまちがい」から順に選ぶ。ねらいの強い順に5段：

1. 形の似た字の入れかえ（シ↔ツ・ソ↔ン・ク↔ワ・ス↔ヌ・ロ↔コ）
2. のばす音「ー」を母音の字にしてしまう（ケーキ→ケエキ）
3. ちいさい字を大きく書いてしまう（コップ→コツプ）
4. だくてん・はんだくてんの付けまちがい（ジ→シ）
5. となりの字の入れかえ（ブラジル→ブラルジ）

- **ちいさい字と「ー」は 5 の対象から外す**。動かすと「ャニーニャー」のようなありえない並びができる
- どれも作れないときだけ、最後に同じ字数の別の語で埋める（ほぼ起きない）

- **手動確認観点**:
  - 答え合わせに理由の一文が毎回出ているか（ここが消えていないか）
  - `naosu` の選択肢が「別の語」ではなく「書きまちがい」になっているか
  - けっか画面の見出しが `nigata` のときだけ「まちがえた 字」になっているか
