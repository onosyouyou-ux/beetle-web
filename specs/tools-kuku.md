# かけざん修行（`tools/kuku/`）

- **目的**: 九九81問を、教科書どおりの**となえかた**（「さんにが ろく」）で覚える子ども向けの静的アプリ。
  小2の2学期に習う九九の、暗唱の入口をそのままアプリにしたもの
- **中心の仕掛け**: 出題の本命は **となえかた**（`q` だけを出して こたえを選ばせる。「にしが」→ はち）。
  音だけの丸暗記は忘れたときに戻れないので、**まちがえたら●のアレイ図を自動で出す**。
  この2つが芯で、どちらを外しても ただの4択計算ドリルになる
- **読み上げ（音声合成）は入れない**。九九は子どもが声に出すもので、平坦な抑揚はリズムを壊す。
  要望が来ても、この判断を先に確認すること
- **レイアウト型**: 教育系の静的アプリ（[_common.md](_common.md) 参照）。紙面 `.app-paper` 1180px ＋ モザイクタイル背景。
  SEOは `landing.html` に集約し、アプリ本体の canonical もランディングへ向ける
- **アプリ画面に置くのは あそびかた3ステップだけ**。おうちのかたへ・よくある しつもんはランディング
  （`landing.html` の `#for-family` と `#faq`）に集約し、紙面下部の `.nk-doc-ref` から行く。
  アプリ一覧へは1枚目の画面の盤面の下「← アプリいちらんに もどる」から戻る（2026-09-24に紙面下の `.nk-back-tools` を廃止。行き先が同じで重複していたため）
- **画面のH1は「かけざんしゅぎょう」（かな表記）**。`title`・OGP・JSON-LD は検索向けに「かけざん修行（九九）」とし、
  `title` の後半に「九九の練習」「暗記」など実際に検索される語を残す
- **データ**: `js/kuku-data.js`（`window.KUKU_DATA`）が単一のデータ源。
  `{ a, b, ans, q, y }` の81件で、`q` が といの唱え・`y` が こたえの唱え。
  **唱え方は音便だらけで数字から機械的に作れない**（さざんが・さんぱ・ごっく・はっぱ）ので81問すべてを手で持つ。
  `a` が「1つ分の数」、`b` が「いくつ分」で、●のアレイ図は `b` 行 × `a` 個（3×2 は ●●● が2行）
  アレイ図の1個は●ではなく**手裏剣の絵**（`shuriken-on.webp` を45度かたむけて「×」の形。2026-09-16）。青い手裏剣は暗い盤に沈むので使わない
- **だんの選択**: データにある段から自動で組み立てる（1〜9の だん）。データが増えれば選択肢も増える。
  **ぜんぶ混ぜる「ランダム」の だんは置かない**（もんだい側の「ランダムに こたえる」と役割がかぶるため。2026-09-17に外した）
- **メニューの並び（2026-09-16）**: 幅のある画面（768px以上）と寝かせた画面は **左＝だん・右＝もんだい** の2カラム、スタートは両方の下。
  だんは **1 2 3／4 5 6／7 8 9 の3列**。スマホ縦は だん→もんだい の縦積み（だんは同じ3列）
- **3つの もんだい**。画面の見出しは「もんだい」。ボタン名どおりの出しかたにする（2026-09-16に作り直し。元の「しき」「ぎゃくびき」はやめた）:
  - `tonae`（おとだけ）: 「にしが」→ こたえを4択。範囲から毎回くじ引きで10問。本命のモード
  - `junban`（じゅんばんに とく）: 「2 × 1」「2 × 2」…と **選んだ段を ×1 から ×9 まで順に9問**
  - `random`（ランダムに こたえる）: 選んだ段を **まぜて重ならずに**9問出す
  - おとだけ（10問）と ほかの2つ（9問）で問題数がちがうので、星は数ではなく **正解の割合** で決める（100%＝3・80%＝2・50%＝1）
- **選択肢は九九のこたえの中だけから作る**。1〜9の外の数（3×11=33 など）は出さない
- **レスポンシブ**: [_common.md](_common.md) の「レスポンシブ共通ルール」に従う（幅は3段固定・タブレットは向きで出し分け）。
  **縦持ち・横持ちのどちらでも、ナビ＋ヒーロー＋盤面が1画面に収まる**こと。9サイズ×3モード＝27パターンで実測ずみ（2026-09-15）
- **色**: `body.ninja-kuku` の `--nk-accent` は青 `#2f6ea8`。既存6アプリ（橙33°・赤12°・青緑179°・紫264°・緑113°）と重ならない色
- **しゅぎょう いちらん**: `nk-link-kuku.webp` を `js/ninja-links.js` に7本目として登録済み（2026-09-16）。
  幅のある画面では3段目の中央に来る（`ninja-kids.css` の `.nk-link:last-child:nth-child(3n+1)`）
- **OGP画像**: `kuku-lp-hero-og.jpg`（ランディングと共用）
- **忍者の絵（2026-09-16）**: ヒーローのキャラは `assets/images/ninja/kuku-groups.webp`（`<img class="ninja-mascot">` と `--nk-mascot`。ランディングの `--nl-art` と共用）。
  問題エリアの隅の道具絵は `assets/images/ninja/items/kuku-items.webp`（`--nk-items`）
- **ヒーローのボタン**: ほかの修行と同じく `js/app-reference.js` で「アプリ一覧」「紹介ページ」を差し込む（2026-09-16）
- **画面の文中の「●」は手裏剣アイコン**（`.kk-ic`。アレイ図と同じ `shuriken-on.webp` を45度）。ヒントのボタンも「（手裏剣） で みる」。
  meta・JSON-LD・紹介ページ・一覧カードの文字は画像を置けないので **★** で書く（●はやめる。2026-09-16）
- **ヒントの下の一文は こたえを書かない**:「9の まとまりが 8こ あるから…」。答えは子どもに出させる
- **選択肢の数字は `--kk-opt-fs`（`clamp(24px, --nk-qh × .14, 44px)`）**。忍具アイコンも同じ大きさにして天地の中心をそろえる。ことばの修行の `--nk-fs-opt` だと数字だけ小さく見えた
- **2カラムの段でヒントを出したら**、「こたえは?」の札の高さぶん中身を下げる（札の下に といの字がかくれた）
- **寝かせたスマホ（`max-height:500px`）のメニュー**: だんの注記（1×1〜1×9）を隠し、すき間を詰めてスタートまで1画面に入れる
- **未了**: 背景の1枚絵（`kuku-bg-v1.webp`）がまだ無い。絵ができたら `ninja-kids.css` に `--nk-bg-img` を足す
- **手動確認観点**: となえかたの「が」が正しく出ること（こたえが1けたのときだけ）／
  まちがえたときに手裏剣の図が自動で出ること／じゅんばんは ×1→×9 の順・ランダムは同じ式が2回出ないこと
