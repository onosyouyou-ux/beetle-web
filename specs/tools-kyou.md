# きょうの しゅぎょう（`tools/kyou/`。#143・2026-10-11）

- **目的**: 修行アプリ8本を またいで、毎日5もん。1本だけで遊んでいる子に ほかの修行を見せる入口
- **出しかた**: 日づけで8本から5本を えらび、1本1もんずつ4択。**問題も日づけで決まる**（その日は だれが開いても同じ5もん。クラスで「きょうの5もん」として使える）。
  くじは `kyou:YYYY-MM-DD` を種にした mulberry32。むずかしさは どの修行も いちばん やさしい段
  - かんじ：小1の ことば → よみ（にごる・っ・のばす音を1か所かえた形＋ほかの ことばの よみ）
  - カタカナ：ひらがな → カタカナ（シ／ツ・ソ／ン などの にた字、ー・ッ の つけわすれ）
  - ローマ字：レベル1〜3の ことば → ヘボン式（母音を1つ かえた形。**訓令式は まちがいの選択肢に しない**）
  - フォニックス：3もじの ことば → よみ（1もじ ちがいの ことばの よみ）
  - とけい：ちょうど・30ぷん（みじかい はりを となりで よんだ形）
  - さんすう：10までの たし・ひき／かけざん：九九（となりの だん・ひとつ ずれ）／さくらんぼざん：くりあがりの たしざん
- **データ**: 各アプリの `js/*-data.js` を そのまま読む。アプリ本体の JS は読まない（読みこむと すぐ メニューを描くので部品として借りられない）。
  選択肢の作りかたは `js/kyou.js` に小さく持つ
- **見た目**: 盤面と けっか は かけざん修行の部品（`kk-`。`kuku.css`＋`ninja-kids.css`）を借り、差分は `css/kyou.css`。
  body は `ninja-kids ninja-kuku ninja-kyou`。色は赤むらさき `#b0407a`（8本と かぶらない）
- **きろく**: localStorage `nk-kyou`（`done: {日づけ: 正解数}`、60日ぶん）。メニューに「きょうは できた！」と れんぞく日数
- **入口**: 8本の しゅぎょう いちらん（`ninja-links.js`）の まきもの の下に「きょうの しゅぎょう」ボタン。
  いちらん の札は「きょうの おすすめ」（日づけだけで決まる1本。どのページでも同じ1本）
- **GA4**: `app: 'kyou'`・`mode: 'kyou'`・`level: 'none'`
- **レスポンシブ**: [_common.md](_common.md) の共通ルール。メニューは PC で5本を横1列、スマホは1本1行。
  1440x900・1366x657・1093x520・390x660 でスタートが1画面に入ることを実測（2026-10-11）
- **手動確認観点**: 選択肢が4つとも ちがう字か／正解の印が1つか／とけいの「なんじ?」の札が 時計に かからないか
